# havelock v0.1 Implementation Plan

> Historical record: the plan the package was built from (2026-10-11), kept unedited apart from local paths. It was
> written for AI coding agents; the code and the user docs (`docs/quickstart.md`, `docs/models.md`,
> `docs/certificates.md`) are authoritative where they differ.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `havelock` 0.1.0 Python package and CLI. For a vortex model and a number N of vortices, it returns the stability threshold of the regular N-ring, the critical Fourier mode, the nonlinear verdict at the bifurcation point, a simulation of the motion, and exactly verifiable certificates (JSON, and Lean for the tanh model). Every answer is labelled PROVED, CERTIFIED or NUMERICAL.

**Architecture:** Each model module (`models/mt.py`, `models/tanh.py`) holds its Hamiltonian in Cartesian form (mpmath, numpy and sympy versions) and its parameter conversions. `blocks.py` turns the papers' Fourier-block formulas into integer numerator polynomials (python-flint). `certify.py` isolates roots with Arb and checks them exactly (Sturm counts, exact signs). The public functions `threshold`, `stability`, `nonlinear`, `simulate` and `certificate` all return `Result` subclasses. The certificate verifier rebuilds the polynomials by itself from the closed forms. The Montaldi–Tokieda (MT) family comes first (Tasks 1–10). The tanh model comes after a gate on the Boatto check (Tasks 11–13). Each tanh task is self-contained.

**Tech Stack:** Python ≥ 3.10, mpmath, sympy, numpy, scipy, python-flint, pytest, setuptools (src layout), GitHub Actions. Lean 4 is optional and is used only in CI.

**Spec:** `docs/design/2026-10-11-havelock-package-design.md` (binding). Read it before Task 1.

## Review Focus

1. **Very large N in the MT family** (for example `threshold("sinh", 10001)`, or certificates for N = 501). A user expects an exact PROVED answer in well under a second, because everything is a closed form or a quadratic. Tests: `test_review_focus_large_n_stays_exact` (Task 5) and `test_review_focus_large_n_certificate` (Task 9).
2. **tanh N above the paper's table but under the size cap** (17 ≤ N ≤ 64). A user expects a CERTIFIED threshold, critical mode ⌊N/2⌋, the degree pattern of eq. (deg), and a certificate that verifies. Tests: `test_review_focus_beyond_the_table` (Task 12) and `test_review_focus_beyond_the_table_certificates_verify` (Task 13).
3. **Hand-edited, truncated or non-object certificate JSON** given to `havelock verify`. A user expects an INVALID report (or CLI exit code 2 for a missing file), never a traceback. Tests: `test_review_focus_malformed_json_is_invalid_not_a_crash` and `test_review_focus_garbage_interval` (Task 9), and the missing-file case in `test_errors_exit_2` (Task 10).
4. **Parameter values on a domain edge**: the equator `lam_r2 = 1`, and rings very close to the boundary of H². A user expects exact verdicts with no singularity. Test: `test_review_focus_domain_edges` (Task 6).
5. **A float typed at a threshold** (for example `float(b_8)`). A user expects the exact binary value of the float to decide the verdict ("EM-stable" or "unstable"), never a "degenerate" verdict and never a float-comparison artefact. Test: `test_review_focus_float_near_threshold_is_decided_exactly` (Task 6).

## Decisions taken in this plan (spec ambiguities resolved)

- **MT domain.** `lam_r2 ∈ (−1, 1]`, as in paper §1 ("b ∈ (−1,1]"). The values b and 1/b give the same ring reflected through the equator, so b > 1 raises `InvalidInput`. The views are: `sphere` (0, 1], `plane` {0}, `sinh` (−1, 0).
- **MT N = 2, 3.** For `mt` and `sphere`, `threshold` and `nonlinear` raise `OutOfValidityRange`, because the only root of eq. (bn) is at the equator, which the paper excludes. For `plane` and `sinh` the ring is stable at every radius (PROVED). For `plane`, N = 7 returns a `Threshold` at 0: the plane has no length scale, so every ring sits at b_7 = 0.
- **Normalisations follow the papers.** MT blocks use H = −Σ log|z_i−z_j|² + (n−1)Σ log σ (paper eq. (H)): a_m = C1 − m(n−m), b_m = m(n−m). tanh blocks use H = Σ(−ln|z_i−z_j| + ln|1−z_i z̄_j|) (note eq. (H)). Every printed number therefore matches its own paper.
- **`precision`** is the starting Arb precision in bits (≥ 64). The ladder is (256, 512, 1024, 2048, 4096) bits.
- **`stability(value)`** uses the value exactly. A float is converted to its exact binary value, and strings such as `"1/7"` and `"-0.3"` are exact rationals. All signs are therefore exact. The status is PROVED for the MT family and CERTIFIED for tanh. An exact zero of some a_m, or a Krein window, gives "spectrally-stable-only" and the basis says which.
- **tanh `nonlinear` for odd N** raises `OutOfValidityRange`. At ξ* the critical block has a b − g² = −g² < 0 (the Krein window), the Hessian is indefinite, and the quartic test does not apply. For even N, c4 comes from the level-set engine (NUMERICAL).
- **Certificate format extensions** (spec §7 lists the fields; three are added so that `verify` can prove stability on the whole stable side, not only at two points). `mode` is the critical mode. `points` are the two rational sample points. `stable_side` holds the open interval between the threshold interval and the domain end, with Sturm root counts of every A_m and B_m there (all must be 0). A_m, B_m and D_m are the integer numerators of a_m, b_m and a_m b_m − g_m². `factor_index` refers to the irreducible factors of `polynomial`: primitive, leading coefficient > 0, sorted by (degree, coefficients). D_m signs are recorded whenever some g_m ≠ 0.
- **MT certificates** use the same format. Their polynomial is the quadratic numerator of a_⌊n/2⌋. `to_lean` exists for tanh only. MT thresholds are already proved in Lean (`Havelock.Conj13.bn_spec`, `Havelock.Sinh`).
- **Simulation.** The default perturbation is along the critical radial mode. A `seed` switches to a Gaussian perturbation of every coordinate. Deviation is measured with the model's pair invariant, which is a function of the geodesic distance and so is blind to rigid motions. `drift_tolerance = 1e3 · rtol`. `growth` is NaN when `perturb = 0`.
- **Research reproduction (spec 9.7).** `REPRODUCE.md` does not exist yet. The reproduction tests read the committed outputs directly: `tanh/certify_v2.out` (minimal polynomials and 50-digit ξ* for N = 8..16) and `conj13/paper/table_check.out` (c4 for n = 4..25).
- **Lean CI (spec 9.4)** gets its own workflow, `.github/workflows/lean-export.yml`, so `lean.yml` is left alone.
- **The Lean mod-p irreducibility certificate** (spec §6, "Lean library additions") is not part of this plan. `lean/` belongs to the Lean workstream, and the spec lets the item be dropped from v0.1 without blocking the release. The package records the mod-p witness in every tanh certificate (`irreducibility_witness`), and `verify` re-checks it. The degrees stay labelled "CERTIFIED by computer algebra".
- **Two small modules beyond the spec's component list:** `stability.py` (the `stability()` function) and `limits.py` (the documented limits). This gives every public function its own file.
- **python-flint floor.** The code uses `fmpz_poly.factor/complex_roots/is_zero`, `fmpq_poly` division with remainder, `nmod_poly.factor`, `arb.mid().man_exp()` and `flint.ctx.prec`. If the CI job on Python 3.10 resolves a python-flint release that lacks one of these, raise the floor in `pyproject.toml` to the oldest release with which `pytest -q` passes, and record it in the commit message.

```python
"""Exception hierarchy (mirrors bolzakit's style; nothing is imported from bolzakit)."""


class HavelockError(Exception):
    """Base class for every error raised by havelock."""


class InvalidInput(HavelockError, ValueError):
    """Unknown model, N < 2, a parameter outside its domain, or a malformed argument.

    Raised before any computation starts."""


class OutOfValidityRange(HavelockError, ValueError):
    """The question is well posed but the answer would be wrong, not merely slow, with the methods available
    (for example the Montaldi–Tokieda family at n = 3, where c4 = 0 and the case rests on MT's own argument)."""


class CertificationFailed(HavelockError):
    """An exact certification could not be completed (precision ladder exhausted, size cap exceeded, or a
    sign pattern that the certificate format cannot express). Raised only when strict=True."""
```

```python
from __future__ import annotations

import copy

#: decimal digits carried by every mpmath value the package returns
WORK_DPS = 50
#: Arb working precisions in bits, tried in order until the certification succeeds
PRECISION_LADDER = (256, 512, 1024, 2048, 4096)
#: simulate(): the reported drift tolerance is DRIFT_FACTOR * rtol
DRIFT_FACTOR = 1e3
#: simulate(): number of output samples
SIM_SAMPLES = 2001
#: nonlinear(): level-set engine settings (decimal digits, number of eps values, eps = k/EPS_DENOM)
LEVELSET = {"dps": 40, "steps": 6, "eps_denominator": 200}
#: largest prime tried when searching for a mod-p irreducibility witness
WITNESS_MAX_PRIME = 20000

_LIMITS = {
    "work_dps": WORK_DPS,
    "precision_ladder_bits": list(PRECISION_LADDER),
    "simulation": {"drift_tolerance": "1e3 * rtol", "default_rtol": 1e-12, "samples": SIM_SAMPLES},
    "nonlinear_levelset": dict(LEVELSET),
    "irreducibility_witness_max_prime": WITNESS_MAX_PRIME,
}


def limits() -> dict:
    """A copy of the documented limits: size caps, precision ladder and tolerances."""
    return copy.deepcopy(_LIMITS)
```

```python
"""Status labels, provenance, and the result classes returned by every public function."""
from __future__ import annotations

import enum
import json
import math
import platform
import time
from dataclasses import dataclass, field, fields, is_dataclass
from fractions import Fraction
from typing import Any

import mpmath as mp
import numpy as np
import sympy as sp


class Status(str, enum.Enum):
    """How an answer is known. PROVED: a paper theorem covers this exact case. CERTIFIED: exact or ball
    arithmetic computed at run time. NUMERICAL: floating point with an error estimate."""

    PROVED = "PROVED"
    CERTIFIED = "CERTIFIED"
    NUMERICAL = "NUMERICAL"

    def __str__(self) -> str:
        return self.value


VERDICTS = ("EM-stable", "spectrally-stable-only", "unstable")


@dataclass(frozen=True)
class Provenance:
    function: str
    inputs: dict
    version: str
    elapsed_s: float
    python: str
    libraries: dict


def make_provenance(function: str, inputs: dict, t0: float) -> Provenance:
    """Provenance record for a call that started at time.perf_counter() == t0."""
    import flint
    import scipy

    from . import __version__

    return Provenance(function=function, inputs=dict(inputs), version=__version__,
                      elapsed_s=time.perf_counter() - t0, python=platform.python_version(),
                      libraries={"mpmath": mp.__version__, "sympy": sp.__version__, "numpy": np.__version__,
                                 "scipy": scipy.__version__, "python-flint": flint.__version__})


def jsonable(v: Any) -> Any:
    """Convert a result (or any value inside one) to plain JSON types. Fractions become "p/q" strings and
    mpmath numbers become decimal strings with all their digits, so no precision is lost."""
    if isinstance(v, enum.Enum):
        return v.value
    if v is None or isinstance(v, (bool, int, str)):
        return v
    if isinstance(v, float):
        return v if math.isfinite(v) else str(v)
    if isinstance(v, Fraction):
        return str(v)
    if isinstance(v, mp.mpf):
        if not mp.isfinite(v):
            return str(v)
        man, _ = v.man_exp
        return mp.nstr(v, max(15, int(abs(int(man)).bit_length() * 0.30103) + 1))
    if isinstance(v, (complex, mp.mpc)):
        return [jsonable(v.real), jsonable(v.imag)]
    if isinstance(v, np.ndarray):
        return [jsonable(x) for x in v.tolist()]
    if isinstance(v, np.generic):
        return jsonable(v.item())
    if is_dataclass(v) and not isinstance(v, type):
        return {f.name: jsonable(getattr(v, f.name)) for f in fields(v) if not f.name.startswith("_")}
    if isinstance(v, dict):
        return {str(k): jsonable(x) for k, x in v.items()}
    if isinstance(v, (list, tuple)):
        return [jsonable(x) for x in v]
    if isinstance(v, sp.Basic):
        return str(v)
    return str(v)
```

```python
"""Model registry, input validation and exact parameter parsing.

A model object exposes: name, family ("mt" or "tanh"), param (native parameter name), stable_side
("below": stable for values below the threshold; "above": stable above it), family_domain (lo, hi, lo_closed,
hi_closed) used by certification, check_value(v), geometry(v), radius(v), xi(v), cosh_r(v), kappa0(v),
chart_radius(v), H_mp(z, v), J_mp(z, v), numpy_kernel(N, v) and sympy_kernel(x1, y1, x2, y2, p, n).
"""
from __future__ import annotations

import math
import numbers
from fractions import Fraction

import mpmath as mp
import sympy as sp

from ..errors import InvalidInput
from .mt import MTView

MODELS = {name: MTView(name) for name in ("mt", "sphere", "plane", "sinh")}


def get_model(name):
    """The model object registered under `name` (case-insensitive)."""
    if not isinstance(name, str) or name.lower() not in MODELS:
        raise InvalidInput(f"unknown model {name!r}; known models: {', '.join(MODELS)}")
    return MODELS[name.lower()]


def check_N(N) -> int:
    """N as an int >= 2 (bools and non-integral values are rejected)."""
    if isinstance(N, bool) or not isinstance(N, numbers.Integral):
        raise InvalidInput(f"N must be an integer, got {N!r}")
    if N < 2:
        raise InvalidInput(f"N must be >= 2, got {N}")
    return int(N)


def to_fraction(value) -> Fraction:
    """Exact rational value of a parameter. Floats are converted exactly (their binary value); strings may be
    decimals or p/q; sympy Rationals and mpmath mpf are accepted. Irrational or non-finite values are rejected."""
    if isinstance(value, bool):
        raise InvalidInput("a parameter value cannot be a bool")
    if isinstance(value, Fraction):
        return value
    if isinstance(value, numbers.Integral):
        return Fraction(int(value))
    if isinstance(value, float):
        if not math.isfinite(value):
            raise InvalidInput(f"parameter value must be finite, got {value!r}")
        return Fraction(value)
    if isinstance(value, str):
        try:
            return Fraction(value.strip())
        except (ValueError, ZeroDivisionError):
            raise InvalidInput(f"cannot parse {value!r} as a rational number") from None
    if isinstance(value, sp.Rational):
        return Fraction(int(value.p), int(value.q))
    if isinstance(value, mp.mpf):
        if not mp.isfinite(value):
            raise InvalidInput(f"parameter value must be finite, got {value!r}")
        man, exp = value.man_exp
        return Fraction(int(man)) * Fraction(2) ** int(exp)
    raise InvalidInput(f"unsupported parameter type {type(value).__name__}; use int, float, str, Fraction, "
                       "sympy.Rational or mpmath.mpf")
```

`src/havelock/models/mt.py`:

```python
"""Montaldi–Tokieda family [MT (1.12)] and its geometry-restricted views.

Chart z in C with sigma = 1 + lam|z|^2, symplectic form sum 2/sigma^2 dx^dy, ring of chart radius r0 = 1 and
native parameter b = lam r0^2 = lam_r2 (paper conj13/paper/main.tex, eq. (H)):
    H = -sum_{i<j} log|z_i - z_j|^2 + (n-1) sum_k log sigma_k,   J = sum_k (x_k, y_k, |z_k|^2) / sigma_k.
b > 0 is the sphere (curvature 4 lam), b = 0 the plane, b < 0 the hyperbolic plane with the sinh interaction.
The domain is (-1, 1]: b and 1/b describe the same ring (reflection through the equator), so b > 1 is excluded.
"""
from __future__ import annotations

from fractions import Fraction

import mpmath as mp
import numpy as np
import sympy as sp

from ..errors import InvalidInput

# name -> (lo, hi, lo_closed, hi_closed)
_DOMAINS = {
    "mt": (Fraction(-1), Fraction(1), False, True),
    "sphere": (Fraction(0), Fraction(1), False, True),
    "plane": (Fraction(0), Fraction(0), True, True),
    "sinh": (Fraction(-1), Fraction(0), False, False),
}


def bn_exact(n: int) -> sp.Expr:
    """b_n of paper eq. (bn) in closed form (Lean Havelock.Conj13.bn): even n, t = sqrt(n-1):
    (1 + 2t - t^2)/(t^2 + 2t - 1); odd n, s = sqrt(n-3): (2 - s)/(2 + s). b_2 = b_3 = 1 (the equator)."""
    if n % 2 == 0:
        t = sp.sqrt(n - 1)
        return sp.radsimp((1 + 2 * t - t**2) / (t**2 + 2 * t - 1))
    s = sp.sqrt(n - 3)
    return sp.radsimp((2 - s) / (2 + s))


def sinh_q(N: int) -> Fraction:
    """q(N) = cosh^2 r* of the sinh model (sinh/note.tex, Section 3)."""
    if N % 2:
        return Fraction(N - 3, 4)
    return Fraction((N - 2) ** 2, 4 * (N - 1))


def c4_closed(n: int) -> Fraction:
    """Level-set quartic coefficient at b_n (paper Theorems even/odd; Lean Havelock.Conj13.c4closed)."""
    if n % 2 == 0:
        m = n - 2
        return Fraction((n - 2) * (m**4 + 40 * m**2 + 48 * m + 16), 192 * n * (n - 1))
    return Fraction((n - 1) * (n - 3) * (n * n - 9 * n + 38), 128 * n)


class MTView:
    family = "mt"
    param = "lam_r2"
    stable_side = "below"
    family_domain = _DOMAINS["mt"]

    def __init__(self, name: str):
        self.name = name
        self.domain = _DOMAINS[name]

    def domain_str(self) -> str:
        lo, hi, lc, hc = self.domain
        if lo == hi:
            return f"{{{lo}}}"
        return f"{'[' if lc else '('}{lo}, {hi}{']' if hc else ')'}"

    def check_value(self, v: Fraction) -> None:
        lo, hi, lc, hc = self.domain
        if not ((lo < v or (lc and v == lo)) and (v < hi or (hc and v == hi))):
            raise InvalidInput(f"{self.param} = {v} is outside the domain {self.domain_str()} of model {self.name!r}")

    @staticmethod
    def geometry(v) -> str:
        return "sphere" if v > 0 else ("plane" if v == 0 else "H2")

    @staticmethod
    def radius(v):
        """Geodesic ring radius with curvature normalised to +-1 (sphere: colatitude; H2: hyperbolic radius);
        for the plane the chart radius r0 = 1."""
        v = mp.mpf(v)
        if v > 0:
            return 2 * mp.atan(mp.sqrt(v))
        if v == 0:
            return mp.mpf(1)
        return 2 * mp.atanh(mp.sqrt(-v))

    @staticmethod
    def xi(v):
        """tanh^2(r/2) on H2 (equal to -lam_r2); None on the sphere and the plane."""
        v = mp.mpf(v)
        return -v if v < 0 else None

    @staticmethod
    def cosh_r(v):
        v = mp.mpf(v)
        return (1 - v) / (1 + v) if v < 0 else None

    @staticmethod
    def kappa0(v):
        """Symplectic density in log-polar coordinates at the ring: omega = kappa0 ds^dtheta."""
        return 2 / (1 + mp.mpf(v)) ** 2

    @staticmethod
    def chart_radius(v):
        return mp.mpf(1)

    @staticmethod
    def H_mp(z, v):
        n = len(z)
        v = mp.mpf(v)
        h = mp.mpf(0)
        for i in range(n):
            for j in range(i + 1, n):
                h -= mp.log(abs(z[i] - z[j]) ** 2)
        for w in z:
            h += (n - 1) * mp.log(1 + v * abs(w) ** 2)
        return h

    @staticmethod
    def J_mp(z, v):
        v = mp.mpf(v)
        s = [1 + v * abs(w) ** 2 for w in z]
        return (mp.fsum(w.real / si for w, si in zip(z, s)), mp.fsum(w.imag / si for w, si in zip(z, s)),
                mp.fsum(abs(w) ** 2 / si for w, si in zip(z, s)))

    @staticmethod
    def sympy_kernel(x1, y1, x2, y2, p, n):
        """(pair term, one-body term, (J1, J2, J3)) as sympy expressions for the level-set engine."""
        u = x1**2 + y1**2
        s = 1 + p * u
        return (-sp.log((x1 - x2) ** 2 + (y1 - y2) ** 2), (n - 1) * sp.log(s), (x1 / s, y1 / s, u / s))

    @staticmethod
    def numpy_kernel(N: int, v: float):
        """Vectorised dH/d(conj z), inverse symplectic density, H, J and the pair invariant |zi-zj|^2/(si sj)."""
        iu = np.triu_indices(N, 1)

        def dH_dzbar(z):
            dz = z[:, None] - z[None, :]
            np.fill_diagonal(dz, 1.0)
            inv = 1.0 / np.conj(dz)
            np.fill_diagonal(inv, 0.0)
            return -inv.sum(axis=1) + (N - 1) * v * z / (1 + v * np.abs(z) ** 2)

        def winv(z):
            return (1 + v * np.abs(z) ** 2) ** 2 / 2

        def H(z):
            d2 = np.abs(z[:, None] - z[None, :])[iu] ** 2
            return -np.log(d2).sum() + (N - 1) * np.log(1 + v * np.abs(z) ** 2).sum()

        def J(z):
            s = 1 + v * np.abs(z) ** 2
            return np.array([(z.real / s).sum(), (z.imag / s).sum(), (np.abs(z) ** 2 / s).sum()])

        def pairq(z):
            s = 1 + v * np.abs(z) ** 2
            return (np.abs(z[:, None] - z[None, :]) ** 2 / (s[:, None] * s[None, :]))[iu]

        return dH_dzbar, winv, H, J, pairq
```

### Task 3: Exact Fourier blocks (MT) and the brute-force Hessian cross-check

The cross-check (spec 9.2) is the guard against a Boatto-type modelling error. It builds the full 2N-dimensional Hessian of F = H − ΩJ₃ by finite differences, from the Cartesian Hamiltonian alone. Ω is solved from the brute-force gradient, and the test checks dF = 0 in every direction. The eigenvalues must equal those of the blocks for every mode m = 0..N−1, including the rotation block.

```python
"""Brute-force finite-difference Hessian of the full 2N-dimensional system (independent of havelock.blocks).

F(u) = H(z(u)) - Omega J3(z(u)), z_k = ring_k exp(s_k + i theta_k), u = (s, theta). Omega is the momentum
multiplier, solved from the brute-force gradient (dH = Omega dJ3 along s_0); the test then checks that dF = 0
in all 2N directions, so the augmented Hamiltonian is critical at the ring. The Hessian is formed by central
differences with step h in mpmath, and its eigenvalues (w.r.t. sum ds^2 + dtheta^2) are returned sorted."""
import mpmath as mp


def fd_spectrum(model, N, v, h, omega_shift=0):
    v = mp.mpf(v)
    rho = model.chart_radius(v)
    ring = [rho * mp.expjpi(mp.mpf(2 * k) / N) for k in range(N)]
    dim = 2 * N

    def Z(u):
        return [ring[k] * mp.exp(u[k] + 1j * u[N + k]) for k in range(N)]

    def shift(u, i, s):
        u = list(u)
        u[i] += s
        return u

    zero = [mp.mpf(0)] * dim
    H = lambda u: model.H_mp(Z(u), v)
    J3 = lambda u: model.J_mp(Z(u), v)[2]
    omega = (H(shift(zero, 0, h)) - H(shift(zero, 0, -h))) / (J3(shift(zero, 0, h)) - J3(shift(zero, 0, -h)))
    omega += omega_shift
    F = lambda u: H(u) - omega * J3(u)
    grad = max(abs(F(shift(zero, i, h)) - F(shift(zero, i, -h))) / (2 * h) for i in range(dim))
    M = mp.matrix(dim, dim)
    f0 = F(zero)
    for i in range(dim):
        M[i, i] = (F(shift(zero, i, h)) - 2 * f0 + F(shift(zero, i, -h))) / h**2
        for j in range(i + 1, dim):
            pp = F(shift(shift(zero, i, h), j, h))
            pm = F(shift(shift(zero, i, h), j, -h))
            mp_ = F(shift(shift(zero, i, -h), j, h))
            mm = F(shift(shift(zero, i, -h), j, -h))
            M[i, j] = M[j, i] = (pp - pm - mp_ + mm) / (4 * h * h)
    E = mp.eigsy(M, eigvals_only=True)
    return sorted(E[k] for k in range(dim)), omega, grad


def block_spectrum(family, N, v):
    """Eigenvalues of all Fourier blocks m = 0..N-1 from havelock.blocks, sorted."""
    from havelock.blocks import blocks_mp

    out = []
    for m in range(N):
        a, b, g = blocks_mp(family, N, m, v)
        s = mp.sqrt(((a - b) / 2) ** 2 + g * g)
        out += [(a + b) / 2 + s, (a + b) / 2 - s]
    return sorted(out)
```

`src/havelock/blocks.py`:

```python
"""Exact Fourier blocks of the energy–momentum Hessian at the regular N-ring, and an mpmath fast path.

In log-polar coordinates z_k = rho e^{2 pi i k/N} e^{s_k + i theta_k}, with the Euclidean structure
sum (ds_k^2 + dtheta_k^2), the Hessian of F = H - Omega J at the ring is block-diagonal over the Fourier modes
m = 0..N-1. On mode m it is the Hermitian matrix [[a_m, i g_m], [-i g_m, b_m]]. Mode 0 carries the rotation
(b_0 = g_0 = 0). Each family supplies integer numerators:
    a_m = A / den_a,   b_m = B / den_b,   g_m = G / den_b,   a_m b_m - g_m^2 = D / (den_a den_b),
with den_a, den_b > 0 on the family's domain and D = A B - (den_a / den_b) G^2.

MT family (paper Proposition prop:blocks, MT (2.6)): a_m = C1 - m(n-m), b_m = m(n-m), g_m = 0,
C1 = 2(n-1)(1+b^2)/(1+b)^2.
"""
from __future__ import annotations

import functools
from dataclasses import dataclass
from fractions import Fraction

import flint
import mpmath as mp
import sympy as sp

from .errors import InvalidInput

X = sp.Symbol("x")
_x = flint.fmpz_poly([0, 1])
_one = flint.fmpz_poly([1])


@dataclass(frozen=True)
class Numerators:
    A: flint.fmpz_poly
    B: flint.fmpz_poly
    G: flint.fmpz_poly
    D: flint.fmpz_poly
    den_a: flint.fmpz_poly
    den_b: flint.fmpz_poly


def _mt_numerators(N: int, m: int):
    T = m * (N - m)
    A = 2 * (N - 1) * (_one + _x**2) - T * (_one + _x) ** 2
    return A, flint.fmpz_poly([T]), flint.fmpz_poly([]), (_one + _x) ** 2, _one


def _mt_exprs(N: int, m: int):
    C1 = 2 * (N - 1) * (1 + X**2) / (1 + X) ** 2
    return C1 - m * (N - m), sp.Integer(m * (N - m)), sp.Integer(0)


_NUMERATORS = {"mt": _mt_numerators}
_EXPRS = {"mt": _mt_exprs}

def _check(family: str, N: int, m: int) -> None:
    if family not in _NUMERATORS:
        raise InvalidInput(f"no Fourier blocks for family {family!r}")
    if not 0 <= m <= N - 1:
        raise InvalidInput(f"mode m must satisfy 0 <= m <= N-1, got m={m}, N={N}")


@functools.lru_cache(maxsize=4096)
def numerators(family: str, N: int, m: int) -> Numerators:
    """Integer numerators and positive denominators of a_m, b_m, g_m and a_m b_m - g_m^2."""
    _check(family, N, m)
    A, B, G, den_a, den_b = _NUMERATORS[family](N, m)
    q, r = divmod(den_a, den_b)
    assert r == 0
    return Numerators(A=A, B=B, G=G, D=A * B - q * G * G, den_a=den_a, den_b=den_b)


def block_exprs(family: str, N: int, m: int):
    """(a_m, b_m, g_m) as sympy rational functions of X (the native parameter), transcribed from the papers."""
    _check(family, N, m)
    return _EXPRS[family](N, m)


def _fq(v: Fraction) -> flint.fmpq:
    return flint.fmpq(v.numerator, v.denominator)


def _frac(q) -> Fraction:
    return Fraction(int(q.p), int(q.q))


def blocks_exact(family: str, N: int, m: int, v: Fraction):
    """(a_m, b_m, g_m) at the rational point v, as exact Fractions."""
    nm = numerators(family, N, m)
    q = _fq(Fraction(v))
    da, db = nm.den_a(q), nm.den_b(q)
    if da == 0 or db == 0:
        raise InvalidInput(f"the blocks are singular at {v}")
    return _frac(nm.A(q) / da), _frac(nm.B(q) / db), _frac(nm.G(q) / db)


def _horner(p: flint.fmpz_poly, v):
    acc = mp.mpf(0)
    for c in reversed(p.coeffs()):
        acc = acc * v + int(c)
    return acc


def blocks_mp(family: str, N: int, m: int, v):
    """(a_m, b_m, g_m) at v in the current mpmath precision (fast path; m = 0 gives the rotation block)."""
    nm = numerators(family, N, m)
    v = mp.mpf(v)
    da, db = _horner(nm.den_a, v), _horner(nm.den_b, v)
    return _horner(nm.A, v) / da, _horner(nm.B, v) / db, _horner(nm.G, v) / db
```

`src/havelock/certify.py`:

```python
"""Exact certification with python-flint: factorisation over Q, Arb root isolation, exact Sturm counts, and
mode-sign checks. No floating-point comparison enters any pass/fail decision: Arb balls are converted to exact
dyadic rationals and every sign is evaluated exactly at a rational point.
"""
from __future__ import annotations

from dataclasses import dataclass, field
from fractions import Fraction

import flint
import mpmath as mp

from .blocks import numerators
from .errors import CertificationFailed
from .limits import PRECISION_LADDER, WITNESS_MAX_PRIME

_x = flint.fmpz_poly([0, 1])


class _Unresolved(Exception):
    """The current Arb precision could not separate the root balls; try the next rung of the ladder."""


def fmpq_of(q: Fraction) -> flint.fmpq:
    return flint.fmpq(q.numerator, q.denominator)


def sign_at(p: flint.fmpz_poly, q: Fraction) -> int:
    v = p(fmpq_of(q))
    return (v > 0) - (v < 0)


def squarefree(p: flint.fmpz_poly) -> flint.fmpz_poly:
    g = p.gcd(p.derivative())
    return p // g if g.degree() > 0 else p


def strip_roots(p: flint.fmpz_poly, roots) -> flint.fmpz_poly:
    """Divide out every factor (q x - p) for the rational roots p/q listed, as often as it divides."""
    for r in roots:
        r = Fraction(r)
        lin = flint.fmpz_poly([-r.numerator, r.denominator])
        while not p.is_zero() and p.degree() > 0 and p(fmpq_of(r)) == 0:
            p = p // lin
    return p


def sturm_count(p: flint.fmpz_poly, lo: Fraction, hi: Fraction) -> int:
    """Number of distinct real roots of p in the half-open interval (lo, hi] (exact Sturm sequence)."""
    if p.degree() <= 0:
        return 0
    s0 = flint.fmpq_poly(squarefree(p).coeffs())
    seq = [s0, s0.derivative()]
    while seq[-1].degree() > 0:
        r = -(seq[-2] % seq[-1])
        if r.is_zero():
            break
        seq.append(r / abs(r.coeffs()[-1]))

    def changes(q: Fraction) -> int:
        qq = fmpq_of(q)
        signs = [v > 0 for v in (s(qq) for s in seq) if v != 0]
        return sum(1 for a, b in zip(signs, signs[1:]) if a != b)

    return changes(lo) - changes(hi)


def _ball(z) -> tuple[Fraction, Fraction]:
    m, e = z.mid().man_exp()
    r, f = z.rad().man_exp()
    mid = Fraction(int(m)) * Fraction(2) ** int(e)
    rad = Fraction(int(r)) * Fraction(2) ** int(f)
    return mid - rad, mid + rad


def real_root_balls(p: flint.fmpz_poly, lo: Fraction, hi: Fraction, bits: int):
    """Exact rational enclosures [L, U] of the real roots of p inside (lo, hi), from Arb (selected by the exact
    test imag == 0). Raises _Unresolved if a real ball meets lo or hi."""
    if p.degree() <= 0:
        return []
    old = flint.ctx.prec
    flint.ctx.prec = bits
    try:
        roots = squarefree(p).complex_roots()
    finally:
        flint.ctx.prec = old
    out = []
    for z, _ in roots:
        if not z.imag.is_zero():
            continue
        L, U = _ball(z.real)
        if lo < L and U < hi:
            out.append((L, U))
        elif not (U < lo or L > hi):
            raise _Unresolved
    return sorted(out)


def canonical_factors(p: flint.fmpz_poly) -> list[flint.fmpz_poly]:
    """Distinct irreducible factors of p over Z: primitive, positive leading coefficient, sorted by
    (degree, coefficients). This order defines `factor_index` in certificates."""
    _, facs = p.factor()
    out = []
    for f, _ in facs:
        if f.coeffs()[-1] < 0:
            f = -f
        out.append(f)
    return sorted(out, key=lambda f: (f.degree(), [int(c) for c in f.coeffs()]))


def _is_prime(n: int) -> bool:
    return n >= 2 and all(n % d for d in range(2, int(n**0.5) + 1))


def mod_p_witness(f: flint.fmpz_poly, max_prime: int = WITNESS_MAX_PRIME):
    """Smallest prime p not dividing lead(f) with f irreducible mod p (this proves f irreducible over Q), as
    {"p": p, "degrees": [deg f]}; None if no such prime <= max_prime."""
    lead = int(f.coeffs()[-1])
    n = f.degree()
    for p in range(2, max_prime + 1):
        if not _is_prime(p) or lead % p == 0:
            continue
        _, fs = flint.nmod_poly([int(c) % p for c in f.coeffs()], p).factor()
        degs = sorted(g.degree() for g, e in fs for _ in range(e))
        if degs == [n]:
            return {"p": p, "degrees": degs}
    return None


@dataclass(frozen=True)
class IsolatedRoot:
    """A real algebraic number: the root of the integer polynomial `poly` (constant term first) in [lo, hi]."""

    poly: tuple
    lo: Fraction
    hi: Fraction

    def __str__(self) -> str:
        return (f"the root in [{float(self.lo):.17g}, {float(self.hi):.17g}] (width {float(self.hi - self.lo):.1e}) "
                f"of the degree-{len(self.poly) - 1} polynomial {list(self.poly)} (constant term first)")

    def approx(self, dps: int = 50):
        with mp.workdps(dps + 5):
            return (mp.mpf(self.lo.numerator) / self.lo.denominator + mp.mpf(self.hi.numerator) / self.hi.denominator) / 2


@dataclass(frozen=True)
class Certification:
    """Everything a threshold certificate records (see havelock.certificates for the JSON form)."""

    family: str
    N: int
    mode: int
    polynomial: flint.fmpz_poly
    factor: flint.fmpz_poly
    factor_index: int
    interval: tuple
    endpoint_signs: tuple
    sturm: int
    points: tuple
    mode_signs: dict
    stable_side: dict
    bits: int
    irreducibility_witness: dict | None = field(default=None)


def _domain_points(dom):
    lo, hi, _, _ = dom
    return Fraction(lo), Fraction(hi)


def coupled(family: str, N: int) -> bool:
    """True if some g_m (1 <= m <= N//2) is not identically zero; then certificates also record a_m b_m - g_m^2."""
    return any(not numerators(family, N, m).G.is_zero() for m in range(1, N // 2 + 1))


def _signs(family: str, N: int, m: int, q: Fraction, with_d: bool) -> dict:
    nm = numerators(family, N, m)
    s = {"A": sign_at(nm.A, q), "B": sign_at(nm.B, q)}
    if with_d:
        s["D"] = sign_at(nm.D, q)
    return s


def certify_threshold(family: str, N: int, domain, stable_side: str, start_bits: int | None = None,
                      witness: bool = False) -> Certification | None:
    """Certify the stability threshold of the N-ring, or return None if no a_m changes sign in the domain.

    Steps: (1) Arb-isolate every real root of every A_m (m = 1..N//2) inside the domain; the threshold is the
    largest root (stable_side "above") or the smallest (stable_side "below"), and its ball must be disjoint from
    all others; (2) select the irreducible factor of A_crit carrying it; (3) exact checks: A_crit changes sign
    across the interval and has exactly one root in it (Sturm); (4) signs of A_m, B_m (and D_m when g != 0) at
    the rational points 2 lo - hi and 2 hi - lo; (5) on the stable side of the interval no A_m or B_m has a root
    (Sturm), and all of them are positive there. Raises CertificationFailed if a check fails."""
    dlo, dhi = _domain_points(domain)
    modes = range(1, N // 2 + 1)
    ladder = [b for b in PRECISION_LADDER if start_bits is None or b >= start_bits] or [start_bits]
    for bits in ladder:
        try:
            balls = []
            for m in modes:
                A = strip_roots(numerators(family, N, m).A, (dlo, dhi))
                balls += [(L, U, m) for (L, U) in real_root_balls(A, dlo, dhi, bits)]
            if not balls:
                return None
            pick = max(balls, key=lambda t: t[1]) if stable_side == "above" else min(balls, key=lambda t: t[0])
            L, U, mode = pick
            if L == U:  # Arb returns an exact rational root as a point ball; widen it to an interval
                L, U = L - Fraction(1, 2**bits), U + Fraction(1, 2**bits)
            for (L2, U2, m2) in balls:
                if (L2, U2, m2) != pick and not (U2 < L or L2 > U):
                    raise _Unresolved
            break
        except _Unresolved:
            continue
    else:
        raise CertificationFailed(f"Arb root isolation did not separate the roots for N={N} "
                                  f"(ladder {list(PRECISION_LADDER)} bits)")
    P = numerators(family, N, mode).A
    factors = canonical_factors(P)
    carrying = [i for i, f in enumerate(factors) if sign_at(f, L) * sign_at(f, U) < 0]
    if len(carrying) != 1:
        raise CertificationFailed("could not identify the irreducible factor carrying the threshold")
    idx = carrying[0]
    es = (sign_at(P, L), sign_at(P, U))
    if es[0] * es[1] >= 0:
        raise CertificationFailed("A_crit does not change sign across the isolating interval")
    st = sturm_count(P, L, U)
    if st != 1:
        raise CertificationFailed(f"Sturm count of A_crit in the interval is {st}, expected 1")
    w = U - L
    below, above = L - w, U + w
    if not (dlo < below and above < dhi):
        raise CertificationFailed("sample points fall outside the domain")
    cd = coupled(family, N)
    mode_signs = {m: {"below": _signs(family, N, m, below, cd), "above": _signs(family, N, m, above, cd)}
                  for m in modes}
    side_lo, side_hi = (U, dhi) if stable_side == "above" else (dlo, L)
    counts = {}
    for m in modes:
        nm = numerators(family, N, m)
        counts[m] = {"A": sturm_count(strip_roots(nm.A, (dlo, dhi)), side_lo, side_hi),
                     "B": sturm_count(strip_roots(nm.B, (dlo, dhi)), side_lo, side_hi)}
    stable_pt, unstable_pt = ("above", "below") if stable_side == "above" else ("below", "above")
    ok_stable = all(mode_signs[m][stable_pt]["A"] > 0 and mode_signs[m][stable_pt]["B"] > 0 for m in modes)
    ok_unstable = mode_signs[mode][unstable_pt]["A"] * mode_signs[mode][unstable_pt]["B"] < 0
    ok_counts = all(c["A"] == 0 and c["B"] == 0 for c in counts.values())
    if not (ok_stable and ok_unstable and ok_counts):
        raise CertificationFailed("the sign pattern on the two sides of the threshold is not the expected one "
                                  "(stable side: every a_m, b_m > 0; unstable side: a_crit b_crit < 0)")
    f = factors[idx]
    return Certification(family=family, N=N, mode=mode, polynomial=P, factor=f, factor_index=idx,
                         interval=(L, U), endpoint_signs=es, sturm=st, points=(below, above),
                         mode_signs=mode_signs,
                         stable_side={"side": stable_side, "interval": (side_lo, side_hi), "root_counts": counts},
                         bits=bits, irreducibility_witness=mod_p_witness(f) if witness else None)


def certify_no_threshold(family: str, N: int, domain) -> bool:
    """True iff every A_m, B_m (and D_m when g != 0), m = 1..N//2, has no root inside the domain and is positive
    at its midpoint (exact Sturm counts): the ring is stable, with positive-definite blocks, at every radius."""
    dlo, dhi = _domain_points(domain)
    mid = (dlo + dhi) / 2
    for m in range(1, N // 2 + 1):
        nm = numerators(family, N, m)
        polys = [nm.A, nm.B] + ([nm.D] if not nm.G.is_zero() else [])
        for p in polys:
            q = strip_roots(p, (dlo, dhi))
            if sturm_count(q, dlo, dhi) != 0 or sign_at(p, mid) <= 0:
                return False
    return True
```

```python
"""threshold(model, N): where the regular N-ring loses stability, which mode goes first, and the basis."""
from __future__ import annotations

import time

import mpmath as mp
import sympy as sp

from .errors import InvalidInput, OutOfValidityRange
from .limits import WORK_DPS
from .models import check_N, get_model
from .models.mt import bn_exact
from .status import NoThreshold, Status, Threshold, make_provenance

_MT_BASIS = ("paper eq. (bn) and Proposition prop:spectral (conj13/paper/main.tex; Montaldi–Tokieda Thm 6, "
             "MT (3.6)): a_m = C1 - m(n-m) with C1 = 2(n-1)(1+b^2)/(1+b)^2 decreasing on (-1, 1], so the ring is "
             "stable for lam_r2 < b_n and the mode floor(n/2) goes first; Lean Havelock.Conj13.bn_spec")
_SINH_BASIS = ("cosh^2 r* = q(N), q = (N-3)/4 (N odd), (N-2)^2/(4(N-1)) (N even) (sinh/note.tex, Section 3; "
               "MT (2.11)); Lean Havelock.Sinh")


def _views_values_relative_to_bn(view: str, bn) -> str:
    """'stable' / 'unstable' if every lam_r2 in the view lies below / above b_n, else 'contains'."""
    if view == "plane":
        return "contains" if bn == 0 else ("stable" if bn > 0 else "unstable")
    if view == "sinh":
        return "contains" if bn < 0 else "stable"
    if view == "sphere":
        return "contains" if bn > 0 else "unstable"
    return "contains"


def _mt_threshold(mdl, N, t0, inputs, strict, precision):
    if N <= 3:
        if mdl.name in ("mt", "sphere"):
            raise OutOfValidityRange(
                f"N = {N}: equation (bn) has its only root at lam_r2 = 1 (the equator), where the momentum is fixed "
                "by all of SO(3) and the threshold analysis (|b| < 1) does not apply; Montaldi–Tokieda treat this "
                "case separately (MT p. 15)")
        return NoThreshold(status=Status.PROVED, basis=f"C1(b) > floor(N^2/4) for every b < 1 when N = {N} "
                           "(paper Proposition prop:blocks)", provenance=make_provenance("threshold", inputs, t0),
                           model=mdl.name, N=N, verdict="stable at every radius",
                           geometry={"plane": "plane", "sinh": "H2"}[mdl.name])
    bn = bn_exact(N)
    where = _views_values_relative_to_bn(mdl.name, bn)
    geometry = {"mt": mdl.geometry(bn), "sphere": "sphere", "plane": "plane", "sinh": "H2"}[mdl.name]
    if where != "contains":
        return NoThreshold(status=Status.PROVED,
                           basis=f"b_{N} = {bn} lies outside the {mdl.name} range {mdl.domain_str()}; " + _MT_BASIS,
                           provenance=make_provenance("threshold", inputs, t0), model=mdl.name, N=N,
                           verdict=f"{where} at every radius", geometry=geometry)
    with mp.workdps(WORK_DPS):
        value = mp.mpf(str(sp.N(bn, WORK_DPS + 10)))
        r, xi, cosh_r = mdl.radius(value), mdl.xi(value), mdl.cosh_r(value)
    basis = _SINH_BASIS if mdl.name == "sinh" else _MT_BASIS
    if mdl.name == "plane":
        basis = "the plane has no length scale: every ring with N = 7 sits at the bifurcation point b_7 = 0; " + basis
    return Threshold(status=Status.PROVED, basis=basis, provenance=make_provenance("threshold", inputs, t0),
                     model=mdl.name, N=N, value=value, exact=bn, mode=N // 2, geometry=geometry,
                     stable_side="below", xi=xi, r=r, cosh_r=cosh_r)


_HANDLERS = {"mt": _mt_threshold}


def threshold(model: str, N: int, *, strict: bool = True, precision: int | None = None):
    """The stability threshold of the regular N-ring in `model`, as a Threshold, or a NoThreshold when the ring
    is stable (or unstable) at every radius. `precision` is the starting Arb precision in bits for certified
    models; `strict=False` allows a NUMERICAL fallback (recorded in `fallback_from`) instead of raising."""
    t0 = time.perf_counter()
    mdl = get_model(model)
    N = check_N(N)
    if precision is not None and (isinstance(precision, bool) or not isinstance(precision, int) or precision < 64):
        raise InvalidInput(f"precision must be an int >= 64 (bits), got {precision!r}")
    if not isinstance(strict, bool):
        raise InvalidInput("strict must be a bool")
    inputs = {"model": mdl.name, "N": N, "strict": strict, "precision": precision}
    return _HANDLERS[mdl.family](mdl, N, t0, inputs, strict, precision)
```

```python
"""stability(model, N, value): the verdict at one parameter value, from exact signs of the Fourier blocks."""
from __future__ import annotations

import time

import mpmath as mp

from .blocks import blocks_exact
from .limits import WORK_DPS
from .models import check_N, get_model, to_fraction
from .status import ModeBlock, Stability, Status, make_provenance

_BASIS = {
    "mt": ("exact rational evaluation of a_m = C1 - m(n-m), b_m = m(n-m), g_m = 0 (paper Proposition prop:blocks, "
           "MT (2.6)); EM-stable = a_m > 0 and b_m > 0 for m = 1..floor(N/2), which makes the reduced Hessian "
           "positive definite (paper Proposition prop:spectral, MT Thm 2)"),
}


def _eigs(a, b, g, kappa0):
    with mp.workdps(WORK_DPS):
        root = mp.sqrt(-mp.mpf(a.numerator) / a.denominator * mp.mpf(b.numerator) / b.denominator + 0j)
        ig = 1j * mp.mpf(g.numerator) / g.denominator
        return (complex((-ig + root) / kappa0), complex((-ig - root) / kappa0))


def stability(model: str, N: int, value) -> Stability:
    """Verdict at lam_r2 (MT family) or xi (tanh) = value. "EM-stable": a_m > 0 and a_m b_m - g_m^2 > 0 for
    every mode m >= 1 (positive-definite energy–momentum Hessian); "spectrally-stable-only": every a_m b_m >= 0
    but the Hessian is not positive definite (a zero mode at a bifurcation point, or a Krein window);
    "unstable": some a_m b_m < 0 (a real pair of eigenvalues). The value is used exactly (floats by their
    binary value), so every sign is decided exactly."""
    t0 = time.perf_counter()
    mdl = get_model(model)
    N = check_N(N)
    v = to_fraction(value)
    mdl.check_value(v)
    with mp.workdps(WORK_DPS):
        kappa0 = mdl.kappa0(mp.mpf(v.numerator) / v.denominator)
    blocks = []
    for m in range(1, N // 2 + 1):
        a, b, g = blocks_exact(mdl.family, N, m, v)
        blocks.append(ModeBlock(m=m, a=a, b=b, g=g, eigenvalues=_eigs(a, b, g, kappa0)))
    em = all(k.a > 0 and k.a * k.b - k.g * k.g > 0 for k in blocks)
    spectral = all(k.a * k.b >= 0 for k in blocks)
    verdict = "EM-stable" if em else ("spectrally-stable-only" if spectral else "unstable")
    basis = _BASIS[mdl.family]
    zero = [k.m for k in blocks if k.a == 0]
    if zero and verdict != "unstable":
        basis += f"; a_m = 0 exactly for m = {zero}: a degenerate (bifurcation) point, see havelock.nonlinear"
    window = [k.m for k in blocks if k.a * k.b > 0 and k.a * k.b - k.g * k.g <= 0]
    if window and verdict == "spectrally-stable-only":
        basis += f"; a_m b_m > 0 but a_m b_m - g_m^2 <= 0 for m = {window}: Krein window, nonlinear stability undecided"
    status = Status.PROVED if mdl.family == "mt" else Status.CERTIFIED
    return Stability(status=status, basis=basis,
                     provenance=make_provenance("stability", {"model": mdl.name, "N": N, "value": str(v)}, t0),
                     model=mdl.name, N=N, value=v, verdict=verdict, geometry=mdl.geometry(v), blocks=tuple(blocks))
```

```python
"""nonlinear(model, N): the quartic coefficient c4 of the reduced Hamiltonian along the kernel at the bifurcation
point, and the verdict it gives. MT family: closed forms (PROVED). The level-set engine below (a port of
conj13/review/c4_levelset.py) evaluates the same quantity numerically for any model; it is used for the tanh model
and to cross-check the closed forms."""
from __future__ import annotations

import functools
import time

import mpmath as mp
import sympy as sp

from .errors import OutOfValidityRange
from .limits import LEVELSET
from .models import check_N, get_model
from .models.mt import c4_closed
from .status import Nonlinear, NoThreshold, Status, make_provenance
from .threshold import threshold

_S = sp.symbols("x1 y1 x2 y2 p n")


@functools.lru_cache(maxsize=None)
def _compiled(name: str):
    x1, y1, x2, y2, p, n = _S
    pair, one, Js = get_model(name).sympy_kernel(x1, y1, x2, y2, p, n)
    v4, v2 = [x1, y1, x2, y2], [x1, y1]

    def lam(e, vs, extra):
        return (sp.lambdify(vs + extra, e, "mpmath"),
                sp.lambdify(vs + extra, [sp.diff(e, a) for a in vs], "mpmath"),
                sp.lambdify(vs + extra, [[sp.diff(e, a, b) for b in vs] for a in vs], "mpmath"))

    return lam(pair, v4, [p]), lam(one, v2, [p, n]), [lam(J, v2, [p, n]) for J in Js]


def _H(name, q, N, p):
    pair, one, _ = _compiled(name)
    dim = 2 * N
    val, g, Hs = mp.mpf(0), [mp.mpf(0)] * dim, mp.zeros(dim, dim)
    for i in range(N):
        for j in range(i + 1, N):
            a, ids = (q[2 * i], q[2 * i + 1], q[2 * j], q[2 * j + 1]), (2 * i, 2 * i + 1, 2 * j, 2 * j + 1)
            val += pair[0](*a, p)
            d, h = pair[1](*a, p), pair[2](*a, p)
            for r in range(4):
                g[ids[r]] += d[r]
                for c in range(4):
                    Hs[ids[r], ids[c]] += h[r][c]
    for i in range(N):
        a = (q[2 * i], q[2 * i + 1])
        val += one[0](*a, p, N)
        d, h = one[1](*a, p, N), one[2](*a, p, N)
        for r in range(2):
            g[2 * i + r] += d[r]
            for c in range(2):
                Hs[2 * i + r, 2 * i + c] += h[r][c]
    return val, g, Hs


def _J(name, q, N, p):
    _, _, Js = _compiled(name)
    dim = 2 * N
    vals, grads, hess = [], [], []
    for J in Js:
        v, g, Hs = mp.mpf(0), [mp.mpf(0)] * dim, mp.zeros(dim, dim)
        for i in range(N):
            a = (q[2 * i], q[2 * i + 1])
            v += J[0](*a, p, N)
            d, h = J[1](*a, p, N), J[2](*a, p, N)
            for r in range(2):
                g[2 * i + r] += d[r]
                for c in range(2):
                    Hs[2 * i + r, 2 * i + c] += h[r][c]
        vals.append(v), grads.append(g), hess.append(Hs)
    return vals, grads, hess


def _vectors(N):
    l, dim = N // 2, 2 * N
    e, e2, t = [mp.mpf(0)] * dim, [mp.mpf(0)] * dim, [mp.mpf(0)] * dim
    for k in range(N):
        ph = 2 * mp.pi * k / N
        e[2 * k], e[2 * k + 1] = mp.cos(l * ph) * mp.cos(ph), mp.cos(l * ph) * mp.sin(ph)
        e2[2 * k], e2[2 * k + 1] = mp.sin(l * ph) * mp.cos(ph), mp.sin(l * ph) * mp.sin(ph)
        t[2 * k], t[2 * k + 1] = -mp.sin(ph), mp.cos(ph)
    unit = lambda v: [a / mp.sqrt(mp.fsum(b * b for b in v)) for a in v]  # noqa: E731
    return unit(e), unit(e2), unit(t)


def _level_set_min(name, N, p, eps, max_iter=60):
    """min { H(q) - H(q0) : J(q) = J(q0), <q - q0, e> = eps, <q - q0, t> = 0, <q - q0, e'> = 0 (N odd) } by
    Newton's method on the KKT system (Cartesian chart coordinates, Euclidean-unit kernel vector e)."""
    mdl = get_model(name)
    dim = 2 * N
    rho = mdl.chart_radius(p)
    q0 = []
    for k in range(N):
        ph = 2 * mp.pi * k / N
        q0 += [rho * mp.cos(ph), rho * mp.sin(ph)]
    e, e2, t = _vectors(N)
    J0, G0, _ = _J(name, q0, N, p)
    _, gH0, _ = _H(name, q0, N, p)
    omega = mp.fsum(gH0[i] * G0[2][i] for i in range(dim)) / mp.fsum(G0[2][i] ** 2 for i in range(dim))
    lin = [e, t] + ([e2] if N % 2 else [])
    rhs = [eps, 0] + ([0] if N % 2 else [])
    nc = len(lin) + 3
    mult = [mp.mpf(0)] * nc
    mult[len(lin) + 2] = omega
    q = [q0[i] + eps * e[i] for i in range(dim)]
    tol = mp.mpf(10) ** (-mp.mp.dps + 8)
    for _ in range(max_iter):
        _, g, Hs = _H(name, q, N, p)
        Jv, Jg, Jh = _J(name, q, N, p)
        cons = [mp.fsum(lin[a][i] * (q[i] - q0[i]) for i in range(dim)) - rhs[a] for a in range(len(lin))]
        cons += [Jv[k] - J0[k] for k in range(3)]
        C = lin + Jg
        L = Hs.copy()
        for k in range(3):
            L -= mult[len(lin) + k] * Jh[k]
        K, r = mp.zeros(dim + nc, dim + nc), mp.zeros(dim + nc, 1)
        for i in range(dim):
            for j in range(dim):
                K[i, j] = L[i, j]
            r[i] = g[i] - mp.fsum(mult[a] * C[a][i] for a in range(nc))
        for a in range(nc):
            for i in range(dim):
                K[i, dim + a], K[dim + a, i] = -C[a][i], C[a][i]
            r[dim + a] = cons[a]
        d = mp.lu_solve(K, -r)
        q = [q[i] + d[i] for i in range(dim)]
        mult = [mult[a] + d[dim + a] for a in range(nc)]
        if mp.norm(d) < tol:
            break
    else:
        raise OutOfValidityRange(f"level-set Newton iteration did not converge (N={N}, eps={eps})")
    return _H(name, q, N, p)[0] - _H(name, q0, N, p)[0]


def c4_level_set(name: str, N: int, p, *, dps: int = LEVELSET["dps"], steps: int = LEVELSET["steps"],
                 eps_denominator: int = LEVELSET["eps_denominator"]):
    """Level-set effective quartic (paper Definition def:c4) by Newton on the KKT system at eps = k/eps_denominator,
    k = 1..steps, symmetrised in +-eps, then Neville extrapolation of f(eps)/eps^4 to eps = 0. NUMERICAL."""
    with mp.workdps(dps):
        p = mp.mpf(p)
        epss = [mp.mpf(k) / eps_denominator for k in range(1, steps + 1)]
        fs = [(_level_set_min(name, N, p, s) + _level_set_min(name, N, p, -s)) / 2 / s**4 for s in epss]
        xs = [s * s for s in epss]
        P = list(fs)
        for k in range(1, len(xs)):
            for i in range(len(xs) - k):
                P[i] = (xs[i + k] * P[i] - xs[i] * P[i + 1]) / (xs[i + k] - xs[i])
        return +P[0]


def _mt_nonlinear(mdl, N, t, t0, inputs):
    if N == 3:
        raise OutOfValidityRange("N = 3: c4 = 0 (the odd-n formula has the factor n - 3); this case rests on "
                                 "Montaldi–Tokieda's own argument (MT p. 15) and is not decided here")
    c4 = c4_closed(N)
    basis = ("paper Theorem thm:even (N even) / thm:odd (N odd): c4 = "
             + ("(n-2)(m^4+40m^2+48m+16)/(192n(n-1)), m = n-2" if N % 2 == 0
                else "(n-1)(n-3)(n^2-9n+38)/(128n)")
             + " > 0, so the ring is Lyapunov stable modulo rotations at b_n (paper Theorem thm:main); "
             "Lean Havelock.Conj13.c4_at_bn (the algebra downstream of the series coefficients)")
    return Nonlinear(status=Status.PROVED, basis=basis, provenance=make_provenance("nonlinear", inputs, t0),
                     model=mdl.name, N=N, value=t.value, mode=t.mode, c4=c4, verdict="stable",
                     method="closed form")


_HANDLERS = {"mt": _mt_nonlinear}


def nonlinear(model: str, N: int) -> Nonlinear:
    """c4 at the bifurcation point of the N-ring and the nonlinear verdict ("stable", "unstable", "undecided")."""
    t0 = time.perf_counter()
    mdl = get_model(model)
    N = check_N(N)
    inputs = {"model": mdl.name, "N": N}
    t = threshold(mdl.name, N)
    if isinstance(t, NoThreshold):
        raise OutOfValidityRange(f"model {mdl.name!r}, N = {N} has no bifurcation point ({t.verdict})")
    return _HANDLERS[mdl.family](mdl, N, t, t0, inputs)
```

```python
"""simulate(model, N, value): direct integration of the 2N-dimensional point-vortex system (always NUMERICAL).
Port of conj13/integrate.py to every model. Hamilton's equations x' = H_y / w, y' = -H_x / w with w the
symplectic density, i.e. z' = -2i (dH/d conj z) / w."""
from __future__ import annotations

import math
import time

import numpy as np
from scipy.integrate import solve_ivp

from .errors import InvalidInput
from .limits import DRIFT_FACTOR, SIM_SAMPLES
from .models import check_N, get_model, to_fraction
from .status import Simulation, Status, make_provenance


def _positive(name, x, upper=math.inf):
    if isinstance(x, bool) or not isinstance(x, (int, float)) or not math.isfinite(x) or not 0 < x <= upper:
        raise InvalidInput(f"{name} must be a finite number in (0, {upper}], got {x!r}")
    return float(x)


def simulate(model: str, N: int, value, *, perturb: float = 1e-4, t_end: float = 100.0, rtol: float = 1e-12,
             seed: int | None = None) -> Simulation:
    """Integrate the ring at `value`, perturbed by relative amplitude `perturb`: along the critical radial mode
    floor(N/2) when seed is None, otherwise by a Gaussian perturbation of every coordinate (numpy seed). DOP853
    with atol = rtol/100. The deviation D(t) is max over pairs of |q_ij(t) - q_ij(ring)| for the model's pair
    invariant q; `growth` = max D / D(0) (NaN when perturb = 0). Energy and momentum drifts are relative to max(1, |initial|) and are
    expected below drift_tolerance = 1e3 rtol."""
    t0 = time.perf_counter()
    mdl = get_model(model)
    N = check_N(N)
    v = to_fraction(value)
    mdl.check_value(v)
    if isinstance(perturb, bool) or not isinstance(perturb, (int, float)) or not math.isfinite(perturb) \
            or not 0 <= perturb < 0.5:
        raise InvalidInput(f"perturb must be in [0, 0.5), got {perturb!r}")
    t_end = _positive("t_end", t_end)
    rtol = _positive("rtol", rtol, 1e-3)
    if seed is not None and (isinstance(seed, bool) or not isinstance(seed, int)):
        raise InvalidInput(f"seed must be an int or None, got {seed!r}")
    vf = float(v)
    dH, winv, H, J, pairq = mdl.numpy_kernel(N, vf)
    rho = float(mdl.chart_radius(vf))
    phi = 2 * np.pi * np.arange(N) / N
    ring = rho * np.exp(1j * phi)
    if seed is None:
        z0 = ring * (1 + perturb * np.cos((N // 2) * phi))
    else:
        rng = np.random.default_rng(seed)
        z0 = ring + perturb * rho * (rng.standard_normal(N) + 1j * rng.standard_normal(N))

    def rhs(t, y):
        z = y[:N] + 1j * y[N:]
        zd = -2j * dH(z) * winv(z)
        return np.concatenate([zd.real, zd.imag])

    ts = np.linspace(0.0, t_end, SIM_SAMPLES)
    sol = solve_ivp(rhs, (0.0, t_end), np.concatenate([z0.real, z0.imag]), method="DOP853", rtol=rtol,
                    atol=rtol * 1e-2, t_eval=ts)
    if not sol.success:
        raise InvalidInput(f"integration failed: {sol.message}")
    Z = sol.y[:N].T + 1j * sol.y[N:].T
    q0 = pairq(ring)
    D = np.array([np.max(np.abs(pairq(z) - q0)) for z in Z])
    Hs = np.array([H(z) for z in Z])
    Js = np.array([J(z) for z in Z])
    e_drift = float(np.max(np.abs(Hs - Hs[0])) / max(1.0, abs(Hs[0])))
    j_drift = float(np.max(np.linalg.norm(Js - Js[0], axis=1)) / max(1.0, float(np.linalg.norm(Js[0]))))
    growth = float(D.max() / D[0]) if D[0] > 0 else float("nan")
    return Simulation(status=Status.NUMERICAL,
                      basis=("scipy DOP853, rtol = %g, atol = rtol/100; Hamilton's equations of the model in its "
                             "chart (conj13/integrate.py)" % rtol),
                      provenance=make_provenance("simulate", {"model": mdl.name, "N": N, "value": str(v),
                                                              "perturb": perturb, "t_end": t_end, "rtol": rtol,
                                                              "seed": seed}, t0),
                      model=mdl.name, N=N, value=v, times=sol.t, trajectory=Z, initial_deviation=float(D[0]),
                      max_deviation=float(D.max()), growth=growth, energy_drift=e_drift, momentum_drift=j_drift,
                      drift_tolerance=DRIFT_FACTOR * rtol)
```

```python
"""Independent exact verifier for threshold certificates (`havelock verify`).

Deliberately self-contained: it rebuilds the block numerators from the papers' closed forms with plain Python
integer lists and re-implements the Sturm count, instead of importing havelock.blocks or havelock.certify. Only
exact integer/rational arithmetic is used (python-flint integer factorisation, fmpq_poly Sturm sequences, Fraction
evaluation); no floating point enters any check.
"""
from __future__ import annotations

from dataclasses import dataclass, field
from fractions import Fraction

import flint

SCHEMA = "havelock-threshold-certificate/1"
_FAMILY = {"mt": "mt", "sphere": "mt", "plane": "mt", "sinh": "mt"}
_DOMAIN = {"mt": (Fraction(-1), Fraction(1))}
_STABLE = {"mt": "below"}


# ---- integer polynomial lists (constant term first) ----
def _add(*ps):
    n = max(len(p) for p in ps)
    return [sum(p[i] for p in ps if i < len(p)) for i in range(n)]


def _mul(p, q):
    out = [0] * (len(p) + len(q) - 1)
    for i, a in enumerate(p):
        if a:
            for j, b in enumerate(q):
                out[i + j] += a * b
    return out


def _sc(c, p):
    return [c * a for a in p]


def _mono(k):
    return [0] * k + [1]


def _trim(p):
    p = list(p)
    while len(p) > 1 and p[-1] == 0:
        p.pop()
    return p


def _mt_numerators(N, m):
    """(A, B, D, G) of the MT family (paper Proposition prop:blocks), constant term first."""
    T = m * (N - m)
    A = _add(_sc(2 * (N - 1), [1, 0, 1]), _sc(-T, [1, 2, 1]))
    return _trim(A), [T], _trim(_sc(T, A)), [0]


_REBUILD = {"mt": _mt_numerators}


def _ev(p, q: Fraction) -> Fraction:
    r = Fraction(0)
    for a in reversed(p):
        r = r * q + a
    return r


def _sign(p, q):
    v = _ev(p, q)
    return (v > 0) - (v < 0)


def _fz(p):
    return flint.fmpz_poly([int(a) for a in p])


def _strip(p, roots):
    P = _fz(p)
    for r in roots:
        lin = flint.fmpz_poly([-r.numerator, r.denominator])
        while P.degree() > 0 and P(flint.fmpq(r.numerator, r.denominator)) == 0:
            P = P // lin
    return P


def _sturm(P: flint.fmpz_poly, lo: Fraction, hi: Fraction) -> int:
    """distinct real roots of P in (lo, hi]"""
    if P.degree() <= 0:
        return 0
    g = P.gcd(P.derivative())
    if g.degree() > 0:
        P = P // g
    s0 = flint.fmpq_poly(P.coeffs())
    seq = [s0, s0.derivative()]
    while seq[-1].degree() > 0:
        r = -(seq[-2] % seq[-1])
        if r.is_zero():
            break
        seq.append(r / abs(r.coeffs()[-1]))

    def V(q):
        qq = flint.fmpq(q.numerator, q.denominator)
        s = [v > 0 for v in (t(qq) for t in seq) if v != 0]
        return sum(1 for a, b in zip(s, s[1:]) if a != b)

    return V(lo) - V(hi)


def _canonical_factors(P: flint.fmpz_poly):
    _, facs = P.factor()
    out = [(-f if f.coeffs()[-1] < 0 else f) for f, _ in facs]
    return sorted(out, key=lambda f: (f.degree(), [int(c) for c in f.coeffs()]))


def _is_prime(n):
    return isinstance(n, int) and n >= 2 and all(n % d for d in range(2, int(n**0.5) + 1))


@dataclass
class VerifyReport:
    ok: bool
    failures: list = field(default_factory=list)
    checks: int = 0

    def __bool__(self):
        return self.ok


def verify_dict(d: dict) -> VerifyReport:
    """Re-check every field of a certificate dict; returns a report listing every failed check."""
    fails, n = [], 0

    def check(cond, msg):
        nonlocal n
        n += 1
        if not cond:
            fails.append(msg)
        return cond

    try:
        if not check(d.get("schema") == SCHEMA, f"schema must be {SCHEMA!r}"):
            return VerifyReport(False, fails, n)
        model, N, mode = d["model"], d["N"], d["mode"]
        if not check(model in _FAMILY, f"unknown model {model!r}"):
            return VerifyReport(False, fails, n)
        fam = _FAMILY[model]
        dlo, dhi = _DOMAIN[fam]
        if not check(isinstance(N, int) and N >= 2 and isinstance(mode, int) and 1 <= mode <= N // 2,
                     "N and mode must be integers with 1 <= mode <= N//2"):
            return VerifyReport(False, fails, n)
        nums = {m: _REBUILD[fam](N, m) for m in range(1, N // 2 + 1)}
        poly = [int(c) for c in d["polynomial"]]
        if not check(_trim(poly) == nums[mode][0], "polynomial is not the numerator A_mode of the critical block"):
            return VerifyReport(False, fails, n)
        lo, hi = (Fraction(s) for s in d["interval"])
        check(dlo < lo < hi < dhi, "interval must satisfy domain_lo < lo < hi < domain_hi")
        factors = _canonical_factors(_fz(poly))
        k = d["factor_index"]
        if check(isinstance(k, int) and 0 <= k < len(factors), "factor_index out of range"):
            f = factors[k]
            fl, fh = f(flint.fmpq(lo.numerator, lo.denominator)), f(flint.fmpq(hi.numerator, hi.denominator))
            check(fl * fh < 0, "the selected irreducible factor does not change sign on the interval")
        es = [_sign(poly, lo), _sign(poly, hi)]
        check(list(d["endpoint_signs"]) == es and es[0] * es[1] < 0,
              "endpoint_signs do not match, or the polynomial does not change sign")
        check(d["sturm"] == 1 and _sturm(_fz(poly), lo, hi) == 1, "Sturm count on the interval is not 1")
        below, above = (Fraction(s) for s in d["points"])
        check(dlo < below < lo and hi < above < dhi, "sample points must lie just outside the interval")
        ms = d["mode_signs"]
        check(sorted(int(m) for m in ms) == list(nums), "mode_signs must list every mode 1..N//2")
        stable_pt = "above" if _STABLE[fam] == "above" else "below"
        unstable_pt = "below" if stable_pt == "above" else "above"
        coupled = any(any(c != 0 for c in G) for (_, _, _, G) in nums.values())
        for m, (A, B, D, _) in nums.items():
            rec = ms.get(str(m), {})
            for where, q in (("below", below), ("above", above)):
                exp = {"A": _sign(A, q), "B": _sign(B, q)}
                if coupled:
                    exp["D"] = _sign(D, q)
                check(rec.get(where) == exp, f"mode_signs[{m}][{where}] = {rec.get(where)} != recomputed {exp}")
                if where == stable_pt:
                    check(exp["A"] > 0 and exp["B"] > 0, f"mode {m} is not stable at the {where} point")
        uA, uB = _sign(nums[mode][0], {"below": below, "above": above}[unstable_pt]), \
            _sign(nums[mode][1], {"below": below, "above": above}[unstable_pt])
        check(uA * uB < 0, "the critical mode is not unstable at the unstable-side point")
        side = d["stable_side"]
        exp_iv = [str(hi), str(dhi)] if _STABLE[fam] == "above" else [str(dlo), str(lo)]
        check(side.get("side") == _STABLE[fam] and [str(Fraction(s)) for s in side["interval"]] == exp_iv,
              "stable_side must be the open interval between the threshold interval and the domain end")
        s_lo, s_hi = (Fraction(s) for s in exp_iv)
        for m, (A, B, _, _) in nums.items():
            got = {"A": _sturm(_strip(A, (dlo, dhi)), s_lo, s_hi), "B": _sturm(_strip(B, (dlo, dhi)), s_lo, s_hi)}
            check(side["root_counts"].get(str(m)) == got and got == {"A": 0, "B": 0},
                  f"stable-side root counts for mode {m}: recorded {side['root_counts'].get(str(m))}, got {got}")
        w = d.get("irreducibility_witness")
        if w is not None and check(isinstance(k, int) and 0 <= k < len(factors), "witness needs a valid factor"):
            f = factors[k]
            p = w.get("p")
            ok_p = check(_is_prime(p) and int(f.coeffs()[-1]) % p != 0, "witness prime must not divide lead(f)")
            if ok_p:
                _, fs = flint.nmod_poly([int(c) % p for c in f.coeffs()], p).factor()
                degs = sorted(g.degree() for g, e in fs for _ in range(e))
                check(w.get("degrees") == degs == [f.degree()], "f is not irreducible modulo the witness prime")
    except (KeyError, TypeError, ValueError, ZeroDivisionError) as e:
        fails.append(f"malformed certificate: {e!r}")
    return VerifyReport(not fails, fails, n)
```

```python
"""Certificate dataclass: JSON export, Lean export (tanh), and verification."""
from __future__ import annotations

import json
import time
from dataclasses import dataclass
from pathlib import Path

from ..certify import certify_threshold
from ..errors import InvalidInput
from ..models import get_model
from ..status import Threshold, jsonable, make_provenance
from .verify import SCHEMA, VerifyReport, verify_dict


def _to_data(t: Threshold, c, prov) -> dict:
    return {
        "schema": SCHEMA, "model": t.model, "N": t.N, "mode": c.mode,
        "polynomial": [int(a) for a in c.polynomial.coeffs()],
        "factor_index": c.factor_index,
        "interval": [str(c.interval[0]), str(c.interval[1])],
        "endpoint_signs": list(c.endpoint_signs),
        "sturm": c.sturm,
        "points": [str(p) for p in c.points],
        "mode_signs": {str(m): v for m, v in c.mode_signs.items()},
        "stable_side": {"side": c.stable_side["side"], "interval": [str(a) for a in c.stable_side["interval"]],
                        "root_counts": {str(m): v for m, v in c.stable_side["root_counts"].items()}},
        "irreducibility_witness": c.irreducibility_witness,
        "provenance": jsonable(prov),
    }


@dataclass(frozen=True)
class Certificate:
    """A machine-checkable threshold certificate (format: docs/certificates.md)."""

    data: dict

    def to_json(self, indent: int | None = 1) -> str:
        return json.dumps(self.data, indent=indent)

    def to_lean(self, path) -> Path:
        """Write a Lean 4 module proving the threshold (tanh model only; it imports Havelock.Tanh.General)."""
        raise InvalidInput("Lean export is available for the tanh model only; MT-family thresholds are proved in "
                           "the Lean library itself (Havelock.Conj13.bn_spec, Havelock.Sinh)")

    @classmethod
    def verify(cls, data) -> VerifyReport:
        """Re-check a certificate (a Certificate, a dict, a JSON string, or a path to a JSON file) exactly.
        A string starting with "{" or "[" is JSON text; any other string is a path."""
        if isinstance(data, Certificate):
            data = data.data
        elif isinstance(data, (str, Path)):
            is_text = isinstance(data, str) and data.lstrip()[:1] in ("{", "[")
            text = data if is_text else Path(data).read_text()
            try:
                data = json.loads(text)
            except json.JSONDecodeError as e:
                return VerifyReport(False, [f"not valid JSON: {e}"], 0)
        if not isinstance(data, dict):
            return VerifyReport(False, ["certificate must be a JSON object"], 0)
        return verify_dict(data)


def certificate(t) -> Certificate:
    """Certificate for a Threshold returned by havelock.threshold (any model)."""
    if not isinstance(t, Threshold):
        raise InvalidInput("certificate() needs a Threshold (a NoThreshold has nothing to certify)")
    t0 = time.perf_counter()
    mdl = get_model(t.model)
    c = t._certification
    if c is None:
        c = certify_threshold(mdl.family, t.N, mdl.family_domain, mdl.stable_side, witness=True)
    prov = make_provenance("certificate", {"model": t.model, "N": t.N}, t0)
    return Certificate(_to_data(t, c, prov))
```

```python
def _num(x, digits=30):
    return mp.nstr(x, digits) if isinstance(x, mp.mpf) else str(x)


def _print_threshold(t):
    if isinstance(t, NoThreshold):
        print(f"{t.model}, N = {t.N}: {t.verdict} ({t.geometry})")
    else:
        side = "below" if t.stable_side == "below" else "above"
        print(f"{t.model}, N = {t.N}: threshold {_num(t.value)} (stable {side}), critical mode {t.mode}, "
              f"geometry {t.geometry}")
        extra = [f"{k} = {_num(getattr(t, k), 20)}" for k in ("xi", "r", "cosh_r") if getattr(t, k) is not None]
        if extra:
            print("  " + ", ".join(extra))
        print(f"  exact: {t.exact}")
    print(f"  status: {t.status}" + (f" (fallback from {t.fallback_from})" if t.fallback_from else ""))
    print(f"  basis: {t.basis}")


def _emit(args, result, human):
    if args.json:
        print(json.dumps(result if isinstance(result, dict) else result.to_dict(), indent=1))
    else:
        human()


def _cmd_threshold(a):
    t = threshold(a.model, a.N, strict=not a.no_strict, precision=a.precision)
    _emit(a, t, lambda: _print_threshold(t))


def _cmd_stability(a):
    s = stability(a.model, a.N, a.value)

    def human():
        print(f"{s.model}, N = {s.N}, value {s.value}: {s.verdict}  [{s.status}]")
        for k in s.blocks:
            print(f"  m = {k.m}: a = {float(k.a):.6g}, b = {float(k.b):.6g}, g = {float(k.g):.6g}")
        print(f"  basis: {s.basis}")

    _emit(a, s, human)


def _cmd_nonlinear(a):
    r = nonlinear(a.model, a.N)
    _emit(a, r, lambda: print(f"{r.model}, N = {r.N}: c4 = {_num(r.c4)} at {_num(r.value, 20)}, verdict "
                              f"{r.verdict}  [{r.status}]\n  basis: {r.basis}"))


def _cmd_simulate(a):
    s = simulate(a.model, a.N, a.value, perturb=a.perturb, t_end=a.t_end, rtol=a.rtol, seed=a.seed)
    summary = {k: v for k, v in s.to_dict().items() if k not in ("times", "trajectory")}
    _emit(a, summary, lambda: print(
        f"{s.model}, N = {s.N}, value {s.value}: growth {s.growth:.4g} (max deviation {s.max_deviation:.3e}), "
        f"energy drift {s.energy_drift:.2e}, momentum drift {s.momentum_drift:.2e} "
        f"(tolerance {s.drift_tolerance:.1e})  [NUMERICAL]"))


def _cmd_cert(a):
    t = threshold(a.model, a.N)
    c = certificate(t)
    if a.json == "-":
        print(c.to_json())
    elif a.json:
        Path(a.json).write_text(c.to_json())
        print(f"wrote {a.json}")
    if a.lean:
        p = c.to_lean(a.lean)
        print(f"wrote {p}")
        if a.check:
            proj = Path(a.lean_project).resolve()
            r = subprocess.run(["lake", "env", "lean", str(Path(p).resolve())], cwd=proj)
            if r.returncode != 0:
                print("Lean check FAILED", file=sys.stderr)
                return 1
            print("Lean check passed")
    if not a.json and not a.lean:
        print(c.to_json())
    return 0


def _cmd_verify(a):
    rep = Certificate.verify(Path(a.cert))
    if a.json:
        print(json.dumps(jsonable(rep), indent=1))
    else:
        print(("VALID" if rep.ok else "INVALID") + f" ({rep.checks} checks)")
        for f in rep.failures:
            print("  - " + f)
    return 0 if rep.ok else 1


def _cmd_limits(a):
    lim = limits()
    _emit(a, lim, lambda: print(json.dumps(lim, indent=1)))


def build_parser() -> argparse.ArgumentParser:
    p = argparse.ArgumentParser(prog="havelock", description="Stability of regular N-vortex rings")
    p.add_argument("--version", action="version", version=f"havelock {__version__}")
    sub = p.add_subparsers(dest="cmd", required=True)

    def add(name, fn, help_):
        s = sub.add_parser(name, help=help_)
        s.set_defaults(fn=fn)
        return s

    s = add("threshold", _cmd_threshold, "stability threshold of the N-ring")
    s.add_argument("model"), s.add_argument("N", type=int)
    s.add_argument("--no-strict", action="store_true", help="allow a NUMERICAL fallback instead of raising")
    s.add_argument("--precision", type=int, default=None, help="starting Arb precision in bits")
    s.add_argument("--json", action="store_true")
    s = add("stability", _cmd_stability, "verdict at one parameter value")
    s.add_argument("model"), s.add_argument("N", type=int), s.add_argument("value")
    s.add_argument("--json", action="store_true")
    s = add("nonlinear", _cmd_nonlinear, "c4 and the nonlinear verdict at the bifurcation point")
    s.add_argument("model"), s.add_argument("N", type=int)
    s.add_argument("--json", action="store_true")
    s = add("simulate", _cmd_simulate, "integrate the perturbed ring (NUMERICAL)")
    s.add_argument("model"), s.add_argument("N", type=int), s.add_argument("value")
    s.add_argument("--perturb", type=float, default=1e-4), s.add_argument("--t-end", type=float, default=100.0)
    s.add_argument("--rtol", type=float, default=1e-12), s.add_argument("--seed", type=int, default=None)
    s.add_argument("--json", action="store_true")
    s = add("cert", _cmd_cert, "threshold certificate (JSON, optionally Lean)")
    s.add_argument("model"), s.add_argument("N", type=int)
    s.add_argument("--json", nargs="?", const="-", default=None, metavar="PATH",
                   help="write the certificate to PATH (stdout if PATH is omitted)")
    s.add_argument("--lean", default=None, metavar="PATH", help="write a Lean module (tanh only)")
    s.add_argument("--check", action="store_true", help="compile the Lean module with `lake env lean`")
    s.add_argument("--lean-project", default="lean", help="Lean project directory (default: ./lean)")
    s = add("verify", _cmd_verify, "re-check a certificate exactly")
    s.add_argument("cert"), s.add_argument("--json", action="store_true")
    s = add("limits", _cmd_limits, "documented limits")
    s.add_argument("--json", action="store_true")
    return p


def main(argv=None) -> int:
    args = build_parser().parse_args(argv)
    try:
        rc = args.fn(args)
    except (HavelockError, OSError) as e:
        print(f"havelock: {type(e).__name__}: {e}", file=sys.stderr)
        return 2
    return rc or 0


if __name__ == "__main__":
    sys.exit(main())
```

````markdown
# Models

| name | Hamiltonian | parameter | stable side |
|---|---|---|---|
| `mt` | Montaldi–Tokieda family [MT (1.12)], chart radius 1 | `lam_r2` = λr₀² ∈ (−1, 1] | below b_n |

Every threshold also reports the geodesic ring radius `r` (curvature normalised to ±1; the chart radius 1 for the
plane), and on H² also `xi` = tanh²(r/2) and `cosh_r`.

## Montaldi–Tokieda family (`mt`, `sphere`, `plane`, `sinh`)

- Hamiltonian H = −Σ log(|z_i − z_j|²/(σ_iσ_j)), σ = 1 + λ|z|², symplectic form Σ 2/σ² dx∧dy
  (conj13/paper/main.tex, eq. (H)). Fourier blocks a_m = C1 − m(n−m), b_m = m(n−m), g_m = 0 with
  C1 = 2(n−1)(1+b²)/(1+b)² (paper Proposition prop:blocks).
- **Threshold, n ≥ 4: PROVED.** b_n from paper eq. (bn); critical mode ⌊n/2⌋. Lean: `Havelock.Conj13.bn_spec`.
  The `sinh` view cites cosh² r* = q(N) (sinh/note.tex; Lean `Havelock.Sinh`). A view that does not contain b_n
  returns `NoThreshold` ("stable at every radius" or "unstable at every radius"), PROVED.
- **c4 at b_n, n ≥ 4: PROVED.** Paper Theorems thm:even / thm:odd; Lean `Havelock.Conj13.c4_at_bn` checks the algebra
  downstream of the series coefficients. Verdict "stable" (Lyapunov stability modulo rotations, paper Theorem
  thm:main).
- **n = 2, 3 on the sphere / full family: OutOfValidityRange.** Eq. (bn) has its only root at the equator b = 1, and
  c4 = 0 at n = 3; the case rests on Montaldi–Tokieda's own argument.
- **stability(): PROVED** from exact signs of the blocks at the (exact rational) value.
- **simulate(): NUMERICAL** always.
````

`docs/certificates.md`:

````markdown
# Threshold certificates

`hv.certificate(threshold)` (CLI: `havelock cert MODEL N --json PATH`) produces a JSON object. `havelock verify PATH`
re-checks every field with exact integer and rational arithmetic only (python-flint factorisation and Sturm
sequences, `fractions.Fraction` evaluation). The verifier rebuilds the block numerators from the closed forms itself;
it does not use the code that produced the certificate.

## Fields (schema `havelock-threshold-certificate/1`)

| field | meaning | how `verify` checks it |
|---|---|---|
| `schema` | format version | equality |
| `model`, `N` | model name and number of vortices | known model, N >= 2 |
| `mode` | critical Fourier mode | 1 <= mode <= N//2 |
| `polynomial` | integer numerator A_mode of a_mode (constant term first) | equals the rebuilt numerator |
| `factor_index` | which irreducible factor carries the threshold (factors primitive, leading coefficient > 0, sorted by degree then coefficients) | the factor changes sign on `interval` |
| `interval` | rational endpoints `"p/q"` | inside the domain; `polynomial` has opposite signs at the ends |
| `endpoint_signs` | signs of `polynomial` at the endpoints | recomputed |
| `sturm` | number of distinct real roots of `polynomial` in the interval | must be 1; recomputed (Sturm) |
| `points` | rational points just below and just above the interval | outside the interval, inside the domain |
| `mode_signs` | for every mode m: signs of A_m, B_m (and D_m = numerator of a_m b_m − g_m², when some g_m ≠ 0) at both points | recomputed; all positive on the stable side; a_mode b_mode < 0 on the other |
| `stable_side` | the open interval between the threshold interval and the domain end on the stable side, with the number of roots of every A_m and B_m in it | recomputed (Sturm); all zero |
| `irreducibility_witness` | optional prime p with the factor irreducible mod p | p prime, p ∤ lead, factorisation degrees mod p equal [deg] |
| `provenance` | package version, inputs, timing | not checked |

Together these prove: the ring is stable on the whole stable side (every a_m, b_m > 0 there), the critical mode is
unstable just across the interval, and the threshold lies in the interval as the unique root there of the
irreducible factor.

`points` and `stable_side` extend the field list of the design spec (Section 7); without them the verifier could
check the signs only at two points, not on the whole stable side.
````

```python
"""The tanh (Kimura) model on H^2 (tanh/note_tanh.tex, eq. (H)).

Poincare disk, metric 4|dz|^2/(1-|z|^2)^2 (curvature -1), symplectic form sum 4/(1-|z_k|^2)^2 dx^dy,
    H = -sum_{j<k} ln tanh(d_jk/2) = sum_{j<k} ( -ln|z_j - z_k| + ln|1 - z_j conj z_k| ),
    J = sum_k ( 2x_k, 2y_k, 1 + |z_k|^2 ) / (1 - |z_k|^2)      (J3 = sum cosh r_k generates rotations).
Native parameter xi = tanh^2(r/2) in (0, 1): the ring has chart radius sqrt(xi) and geodesic radius r.
"""
from __future__ import annotations

from fractions import Fraction

import mpmath as mp
import numpy as np
import sympy as sp

from ..errors import InvalidInput


class TanhModel:
    name = "tanh"
    family = "tanh"
    param = "xi"
    stable_side = "above"
    family_domain = (Fraction(0), Fraction(1), False, False)
    domain = family_domain

    @staticmethod
    def domain_str() -> str:
        return "(0, 1)"

    def check_value(self, v: Fraction) -> None:
        if not 0 < v < 1:
            raise InvalidInput(f"xi = {v} is outside the domain (0, 1) of model 'tanh'")

    @staticmethod
    def geometry(v) -> str:
        return "H2"

    @staticmethod
    def radius(v):
        return 2 * mp.atanh(mp.sqrt(mp.mpf(v)))

    @staticmethod
    def xi(v):
        return mp.mpf(v)

    @staticmethod
    def cosh_r(v):
        v = mp.mpf(v)
        return (1 + v) / (1 - v)

    @staticmethod
    def kappa0(v):
        v = mp.mpf(v)
        return 4 * v / (1 - v) ** 2

    @staticmethod
    def chart_radius(v):
        return mp.sqrt(mp.mpf(v))

    @staticmethod
    def H_mp(z, v):
        n = len(z)
        h = mp.mpf(0)
        for i in range(n):
            for j in range(i + 1, n):
                h += -mp.log(abs(z[i] - z[j])) + mp.log(abs(1 - z[i] * mp.conj(z[j])))
        return h

    @staticmethod
    def J_mp(z, v):
        u = [abs(w) ** 2 for w in z]
        return (mp.fsum(2 * w.real / (1 - ui) for w, ui in zip(z, u)),
                mp.fsum(2 * w.imag / (1 - ui) for w, ui in zip(z, u)),
                mp.fsum((1 + ui) / (1 - ui) for ui in u))

    @staticmethod
    def sympy_kernel(x1, y1, x2, y2, p, n):
        u = x1**2 + y1**2
        re, im = 1 - (x1 * x2 + y1 * y2), y1 * x2 - x1 * y2
        pair = -sp.log((x1 - x2) ** 2 + (y1 - y2) ** 2) / 2 + sp.log(re**2 + im**2) / 2
        return pair, sp.Integer(0), (2 * x1 / (1 - u), 2 * y1 / (1 - u), (1 + u) / (1 - u))

    @staticmethod
    def numpy_kernel(N: int, v: float):
        iu = np.triu_indices(N, 1)

        def dH_dzbar(z):
            dz = z[:, None] - z[None, :]
            np.fill_diagonal(dz, 1.0)
            inv = 1.0 / np.conj(dz)
            np.fill_diagonal(inv, 0.0)
            T = -0.5 * z[None, :] / (1 - np.conj(z)[:, None] * z[None, :])
            np.fill_diagonal(T, 0.0)
            return -0.5 * inv.sum(axis=1) + T.sum(axis=1)

        def winv(z):
            return (1 - np.abs(z) ** 2) ** 2 / 4

        def H(z):
            d = np.abs(z[:, None] - z[None, :])[iu]
            return -np.log(d).sum() + np.log(np.abs(1 - z[:, None] * np.conj(z)[None, :])[iu]).sum()

        def J(z):
            u = np.abs(z) ** 2
            return np.array([(2 * z.real / (1 - u)).sum(), (2 * z.imag / (1 - u)).sum(), ((1 + u) / (1 - u)).sum()])

        def pairq(z):
            return (np.abs(z[:, None] - z[None, :]) ** 2 / np.abs(1 - z[:, None] * np.conj(z)[None, :]) ** 2)[iu]

        return dH_dzbar, winv, H, J, pairq
```

```python
    """note Thm 2 cleared of denominators: A = 2(1-x)^2(1-X)^2 a_m, B = 2(1-X)^2 b_m, G = 2(1-X)^2 g_m, X = x^N."""
    X = _mono(N)
```

```python
"""Lean 4 certificate emitter for tanh thresholds: a port of tanh/lean_gen/gen.py (gen_big and its helpers).

The emitted module imports Havelock.Tanh.General (the block definitions aBlock, bBlock, gBlock and the helpers
peval, dpeval, sign_change) and proves cert_N{N}: xi* is the unique root of f_N in (0,1), enclosed in a 1e-20
interval; every b_m > 0; a_floor(N/2) < 0 below xi*; every a_m > 0 above xi*. Positivity on intervals is shown by
Bernstein-coefficient covers, so every Lean step is `positivity`, `ring`, `norm_num` or `linarith`. For N = 8 the
body is identical to lean/Havelock/Tanh/CertN8.lean. The emitter raises ValueError when one of gen_big's structural
assumptions fails (checked for N = 8..16)."""
from __future__ import annotations

import re
from fractions import Fraction as Fr
from math import comb, lcm

import mpmath as mp
import sympy as sp

_x = sp.Symbol("x")


def _poly(c):
    return sp.Poly(sum(sp.Integer(a) * _x**i for i, a in enumerate(c)), _x)


def _coeffs(P):
    P = sp.Poly(P, _x)
    return [int(P.coeff_monomial(_x**i)) for i in range(P.degree() + 1)]


def _strip(P):
    P = sp.Poly(P, _x)
    a = b = 0
    while P.eval(0) == 0:
        P = sp.quo(P, sp.Poly(_x, _x)); a += 1
    while P.eval(1) == 0:
        P = sp.quo(P, sp.Poly(_x - 1, _x)); b += 1
    return P, a, b


def _ev(c, q):
    r = Fr(0)
    for a in reversed(c):
        r = r * q + a
    return r


def _bern(c, u, v):
    n = len(c) - 1; u = Fr(u); v = Fr(v); h = v - u
    cc = [Fr(a) for a in c]
    t = [sum(cc[i] * comb(i, k) * u ** (i - k) for i in range(k, n + 1)) for k in range(n + 1)]
    a = [t[k] * h**k for k in range(n + 1)]
    bb = [sum(Fr(comb(k, i), comb(n, i)) * a[i] for i in range(k + 1)) for k in range(n + 1)]
    return [bb[k] * comb(n, k) / h**n for k in range(n + 1)]


def _nice_mid(u, v):
    u = Fr(u); v = Fr(v)
    d = 1
    while True:
        lo = u * d; k = int(lo) + 1
        if Fr(k, d) < v and Fr(k, d) > u:
            mid = (u + v) / 2; k = round(mid * d)
            if u < Fr(k, d) < v:
                return Fr(k, d)
        d *= 2 if d < 16 else 10


def _cover(c, u, v, depth=0):
    b = _bern(c, u, v)
    if all(z >= 0 for z in b) and any(z > 0 for z in b):
        return [("piece", Fr(u), Fr(v), b)]
    if depth >= 40:
        raise ValueError("Bernstein subdivision found no positivity cover")
    w = _nice_mid(u, v)
    if not _ev(c, w) > 0:
        raise ValueError(f"polynomial not positive at split point {w}")
    return _cover(c, u, w, depth + 1) + [("pt", w)] + _cover(c, w, v, depth + 1)


def _lit(q):
    q = Fr(q)
    if q.denominator == 1:
        return "(%d : ℝ)" % q.numerator
    return "((%d : ℝ) / %d)" % (q.numerator, q.denominator)


def _L(c):
    return "[" + ", ".join(str(a) for a in c) + "]"


def _den(N, kind):
    if kind == "A":
        return "(mul_pos (mul_pos two_pos (pow_pos h1x 2)) (pow_pos hX 2))"
    if kind == "B":
        return "(mul_pos two_pos (pow_pos hX 2))"
    return "(mul_pos (mul_pos four_pos (pow_pos h1x 2)) (pow_pos hX 4))"


def _blockexpr(N, m, kind):
    if kind == "A":
        return f"aBlock {N} {m} x"
    if kind == "B":
        return f"bBlock {N} {m} x"
    return f"aBlock {N} {m} x * bBlock {N} {m} x - gBlock {N} {m} x ^ 2"


def _sym_rw(N, m, mp_, kinds):
    r = []
    if "A" in kinds:
        r.append(f"show aBlock {N} {m} x = aBlock {N} {mp_} x from aBlock_symm {N} {mp_} (by norm_num) x")
    if "B" in kinds:
        r.append(f"show bBlock {N} {m} x = bBlock {N} {mp_} x from bBlock_symm {N} {mp_} (by norm_num) x")
    if "D" in kinds:
        r.append(f"show gBlock {N} {m} x = -gBlock {N} {mp_} x from gBlock_symm {N} {mp_} (by norm_num) x, neg_sq")
    return "rw [" + ", ".join(r) + "]"


class _Emitter:
    def __init__(self, numer):
        self.numer = numer      # numer(N, m, kind) -> list[int], constant term first
        self.out: list[str] = []

    def emit(self, s):
        self.out.append(s)

    def pos_lemma(self, name, c, u, v):
        if len(c) == 1:
            if not c[0] > 0:
                raise ValueError("constant polynomial is not positive")
            self.emit(f"""theorem {name} (x : ℝ) (hu : {_lit(u)} < x) (hv : x < {_lit(v)}) :
    0 < peval {_L(c)} x := by norm_num [peval]
""")
            return 1
        pieces = _cover(c, u, v)
        subs = []
        for p in pieces:
            if p[0] != "piece":
                continue
            _, pu, pv, b = p
            K = lcm(*[z.denominator for z in b])
            ints = [int(z * K) for z in b]; n = len(b) - 1
            terms = []
            for k, ck in enumerate(ints):
                if ck == 0:
                    continue
                t = str(ck)
                if k > 0:
                    t += " * p ^ %d" % k
                if n - k > 0:
                    t += " * q ^ %d" % (n - k)
                terms.append(t)
            expr = " + ".join(terms)
            sub = "%s_%d" % (name, len(subs))
            subs.append(sub)
            self.emit(f"""theorem {sub} (x : ℝ) (hu : {_lit(pu)} < x) (hv : x < {_lit(pv)}) :
    0 < peval {_L(c)} x := by
  have hB : ∀ p q : ℝ, 0 < p → 0 < q → 0 < {expr} := by
    intro p q hp hq; positivity
  have key : ({K} : ℝ) * peval {_L(c)} x =
      (fun p q : ℝ => {expr}) (x - {_lit(pu)}) ({_lit(pv)} - x) := by
    simp only [peval]; push_cast; ring
  have h' : 0 < ({K} : ℝ) * peval {_L(c)} x := by
    rw [key]; exact hB _ _ (by linarith) (by linarith)
  exact pos_of_mul_pos_right h' (by norm_num)
""")
        pts = [p[1] for p in pieces if p[0] == "pt"]
        if not pts:
            self.emit(f"""theorem {name} (x : ℝ) (hu : {_lit(u)} < x) (hv : x < {_lit(v)}) :
    0 < peval {_L(c)} x := {subs[0]} x hu hv
""")
            return 1
        s = f"""theorem {name} (x : ℝ) (hu : {_lit(u)} < x) (hv : x < {_lit(v)}) :
    0 < peval {_L(c)} x := by
"""
        ind = "  "
        for j, w in enumerate(pts):
            low = "hu" if j == 0 else "h%d" % (j - 1)
            s += f"{ind}rcases lt_trichotomy x {_lit(w)} with h{j} | h{j} | h{j}\n"
            s += f"{ind}· exact {subs[j]} x {low} h{j}\n"
            s += f"{ind}· rw [h{j}]; norm_num [peval]\n"
            if j == len(pts) - 1:
                s += f"{ind}· exact {subs[j + 1]} x h{j} hv\n"
            else:
                s += f"{ind}· "
                s += "__NEXT__"
                ind = ind + "  "
        s = re.sub(r"__NEXT__ +", "", s)
        self.emit(s)
        return len(subs)

    def link_lemma2(self, name, N, m, kind, Pfull):
        S, a, b = _strip(Pfull)
        if b % 2 != 0:
            raise ValueError("odd power of (x - 1) in a block numerator")
        Sc = _coeffs(S.as_expr())
        nat_rw = []
        for (l, r) in [(f"{N} - {m}", N - m), (f"2 * {N} - {m}", 2 * N - m), (f"{N} + {m}", N + m),
                       (f"{N} - {m} + {N}", 2 * N - m), (f"{m} + {N}", N + m), (f"{N} + {N}", 2 * N)]:
            nat_rw.append(f"show ({l} : ℕ) = {r} by norm_num")
        if kind == "A":
            lhs = f"aBlock {N} {m} x * (2 * (1 - x) ^ 2 * (1 - x ^ {N}) ^ 2)"; unf = "aBlock cR"
        elif kind == "B":
            lhs = f"bBlock {N} {m} x * (2 * (1 - x ^ {N}) ^ 2)"; unf = "bBlock W"
        else:
            lhs = (f"(aBlock {N} {m} x * bBlock {N} {m} x - gBlock {N} {m} x ^ 2) * "
                   f"(4 * (1 - x) ^ 2 * (1 - x ^ {N}) ^ 4)"); unf = "aBlock bBlock gBlock W cR"
        rhs = (f"x ^ {a} * " if a else "") + f"(1 - x) ^ {b} * peval {_L(Sc)} x"
        self.emit(f"""theorem {name} (x : ℝ) (h0 : 0 < x) (h1 : x < 1) :
    {lhs} = {rhs} := by
  have hx : (1 : ℝ) - x ≠ 0 := (sub_pos.mpr h1).ne'
  have hX : (1 : ℝ) - x ^ {N} ≠ 0 := (sub_pos.mpr (pow_lt_one₀ h0.le h1 (by norm_num))).ne'
  unfold {unf}
  simp only [{', '.join(nat_rw)}]
  push_cast
  field_simp
  simp only [peval]
  ring
""")
        return a, b, Sc

    def block_pos(self, N, m, kind, lo="0", lohyp="h0", posname=None, linkname=None, a=0, b=4, name=None):
        numer = (f"mul_pos (mul_pos (pow_pos h0 {a}) (pow_pos h1x {b})) ({posname} x {lohyp} h1)") if a else \
            (f"mul_pos (pow_pos h1x {b}) ({posname} x {lohyp} h1)")
        self.emit(f"""theorem {name} (x : ℝ) (h0 : 0 < x) {'' if lo == '0' else f'(hlo : {lo} < x) '}(h1 : x < 1) :
    0 < {_blockexpr(N, m, kind)} := by
  have h1x : (0 : ℝ) < 1 - x := sub_pos.mpr h1
  have hX : (0 : ℝ) < 1 - x ^ {N} := sub_pos.mpr (pow_lt_one₀ h0.le h1 (by norm_num))
  have hn := {numer}
  rw [← {linkname} x h0 h1] at hn
  exact (mul_pos_iff_of_pos_right {_den(N, kind)}).mp hn
""")

    def gen_big(self, N, fc, xs):
        """fc: integer coefficients (constant first) of the irreducible factor carrying xi*; xs: xi* (mpf, >= 30 digits)."""
        P = f"N{N}_"; mc = N // 2
        A = _poly(self.numer(N, mc, "A")); S, a0, b0 = _strip(A)
        if (a0, b0) != (0, 4):
            raise ValueError("A_crit does not have the factor (x - 1)^4 exactly")
        if fc[0] < 0:
            fc = [-c for c in fc]
        fpoly = _poly(fc)
        if not sp.rem(S, fpoly).is_zero:
            raise ValueError("the factor does not divide A_crit")
        Hn = sp.Poly(-sp.quo(S, fpoly), _x)
        Hc = _coeffs(Hn.as_expr())
        if not all(c >= 0 for c in Hc):
            raise ValueError("cofactor of f in A_crit has a negative coefficient")
        ta = Fr(int(mp.floor(xs * 10**20)), 10**20); tb = ta + Fr(1, 10**20)
        if not (_ev(fc, ta) > 0 and _ev(fc, tb) < 0):
            raise ValueError("f does not change sign from + to - across the 1e-20 grid cell of xi*")
        df = [i * fc[i] for i in range(1, len(fc))]; ndf = [-c for c in df]
        dr = [z for z in _poly(df).real_roots() if 0 < z < 1]
        Lm = Fr(0) if not dr else Fr(1, 16)
        if not all(z < Lm for z in dr):
            raise ValueError("f' has a root in (1/16, 1)")
        mx = Fr(0)
        for m in range(1, mc):
            Sm, _, _ = _strip(_poly(self.numer(N, m, "A")))
            for (lo, hi), k in sp.Poly(Sm, _x).intervals(inf=0, sup=1, eps=sp.Rational(1, 10**12)):
                mx = max(mx, Fr(int(sp.numer(hi)), int(sp.denom(hi))))
        k = 4
        while True:
            al0 = Fr(int(mp.floor(xs * 2**k)), 2**k)
            if al0 > mx and al0 < ta:
                break
            k += 1
        nonroot = {}
        for m in range(1, mc + 1):
            a, b, SB = self.link_lemma2(P + f"linkB{m}", N, m, "B", _poly(self.numer(N, m, "B")))
            self.pos_lemma(P + f"posB{m}", SB, 0, 1)
            self.block_pos(N, m, "B", posname=P + f"posB{m}", linkname=P + f"linkB{m}", a=a, b=b, name=P + f"B{m}_pos")
            if m == mc:
                continue
            a, b, SA = self.link_lemma2(P + f"linkA{m}", N, m, "A", _poly(self.numer(N, m, "A")))
            rts = _poly(SA).intervals(inf=0, sup=1)
            if not rts:
                nonroot[m] = True
                self.pos_lemma(P + f"posA{m}", SA, 0, 1)
                self.block_pos(N, m, "A", posname=P + f"posA{m}", linkname=P + f"linkA{m}", a=a, b=b,
                               name=P + f"A{m}_pos")
            else:
                nonroot[m] = False
                self.pos_lemma(P + f"posA{m}", SA, al0, 1)
                self.block_pos(N, m, "A", lo=_lit(al0), lohyp="hlo", posname=P + f"posA{m}",
                               linkname=P + f"linkA{m}", a=a, b=b, name=P + f"A{m}_pos")
        a, b, SA = self.link_lemma2(P + f"linkA{mc}", N, mc, "A", A)
        self.emit(f"""/-- The minimal polynomial `f_{N}` of `ξ*({N})` (constant term first). -/
def f{N} : List ℤ := {_L(fc)}

theorem {P}crit_factor (x : ℝ) : peval {_L(SA)} x = -(peval {_L(Hc)} x * peval f{N} x) := by
  simp only [f{N}, peval]; ring
```
